CrowdStrike 融资/收购/估值 行业 / 商业动态 CNBC

CrowdStrike计划以约439亿美元全股票收购Zscaler，预计2028财年下半年完成。

事实摘要

CrowdStrike计划以约439亿美元全股票收购Zscaler，Zscaler股东每股换得1.135股CrowdStrike股票，交易预计在CrowdStrike 2028财年下半年完成。

CrowdStrike股价下跌9%，Zscaler上涨近18%。 该交易将把CrowdStrike带入网络安全市场；

CEO George Kurtz称，将借Zscaler构建可部署AI、控制AI并让任意Agentic应用安全运行的单一控制面，并称看到成为全球最大AI安全与防护公司的路径。

编辑解读

这起交易是CrowdStrike迄今最大收购，也被文章列入网络安全行业整合潮：Google此前宣布320亿美元收购Wiz，Cisco在2024年以约280亿美元收购Splunk。

Dragos 监管/安全/隐私 政策、安全与社会影响 补录 · 2026-11-22 发布 The Decoder

Dragos 称约200万次测试请求发现至少三家AI推理服务商被入侵，OpenRouter 作为回应下架三家供应商并撤销125个端点的ZDR批准。

事实摘要

Dragos 安全研究人员在2026年的7月至11月间向AI服务商发送约200万次携带虚假凭据的请求，识别出至少三家已被入侵、攻击者正在窃取用户数据的供应商。 在最大一起事件中，攻击者获取数百个AWS密钥，包括供应商在处理前已拒绝的请求中的密钥；

部分案例中，他们在数小时内测试密钥、搜索S3存储并尝试建立持久访问。三家供应商在被Dragos通知前均不知情。 Dragos 称，模型市场转售商无需利用漏洞，最低价加上开启日志就足以读取客户请求；“零数据保留”（ZDR）等隐私设置常被忽略。

OpenRouter 作为回应将三家供应商移出平台、撤销125个端点的ZDR批准（部分出于研究结果、部分作为预防），并邮件警告受影响用户第三方可能读取了发往 MiniMax 模型的请求。

编辑解读

这类风险可用自设 canary token 做持续监测；OpenRouter 的处置属部分响应，受影响供应商中并非全部已发布安全报告。

智谱（Z.ai） 模型/产品发布 基础模型与技术 补录 · 2026-11-23 发布 simonwillison.net

智谱Z.ai上线GLM-5.4，称其为自家首个循环Transformer模型且暂未开放权重。

事实摘要

据 Simon Willison 于2026年11月23日发布的博客，智谱（Z.ai）已上线 GLM-5.4，Z.ai 将其描述为自家首个采用循环 Transformer 架构的模型。

按文中转述的 Z.ai 说法，循环 Transformer 让一组共享权重的层在一次前向中多次迭代、细化上一轮的隐藏状态，从而在不增加参数量的前提下得到更深的网络。

GLM-5.4 目前尚未开放权重，需要通过 Z.ai 的 Coding Plan 订阅访问，普通 API 暂不可用，但两者共用 https://api.z.ai/api/v1 的 OpenAI 兼容 Responses API。

作者指出这是过去一周内第二次看到循环 Transformer，前一次是 Thinking Machines Lab 于11月20日发布的 Inkling 2 Mini，其对每个 token 的中层运行三次以提升推理质量。

作者用 pelican 提示做了低、高、最高三档对比，称 GLM-5.3 与 5.4 出图质量相近，且 5.3、5.4 的风格更接近 OpenAI 和 Anthropic 模型，5.1 与 5.2 则差异明显。

编辑解读

后续需 Z.ai 补充 GLM-5.4 的参数规模、公开评测与消融数据，并明确是否开放权重；当前对循环架构收益的判断主要来自厂商描述和作者的主观出图对比。

Anthropic 模型/产品发布 Agent 技术 TechCrunch

Anthropic 发布 Claude Ship，AI Agent 可依团队策略自动审批代码变更，审批 Agent 仍处 beta。

事实摘要

Anthropic 发布 Claude Ship，一套用于自动完成代码审查、修复和例行变更审批的 AI Agent 套件，其中 Code Review 已正式可用，PR Steward 与 Claude Approvals 处于 beta。

PR Steward 处理 CI 检查失败、合并冲突和 Code Review 反馈，并在每次推送后说明改了什么、需要时如何回滚；

Claude Approvals 则执行团队以自然语言写入仓库的策略文件，可结合 Code Review 结论或公司自有分类器作出批准。

该套件面向 GitHub 仓库的 Claude Team 与 Enterprise 套餐开放，Anthropic 建议 beta 阶段先以仅观察模式运行，可限定单一仓库并设置月度支出上限，团队仍掌握运行位置、Quick/Standard/Deep 审查级别以及哪些变更转人工。

编辑解读

Claude Ship 中只有 Code Review 已正式可用，PR Steward 与 Claude Approvals 仍为 beta，自动审批目前属于需先以仅观察模式试用的实验能力。

报道以“newly public AI company”指称 Anthropic，但文章主体是开发工具发布，而非上市进展。

SpaceX 监管/安全/隐私 政策、安全与社会影响 theverge · CNBC · WIRED

俄勒冈与弗吉尼亚两州起诉 SpaceX，指控 Grok 与 X 未设有效防护并虚假宣传安全性

事实摘要

据 The Verge、CNBC 与 Wired 报道，俄勒冈州总检察长 Dan Rayfield 与弗吉尼亚州总检察长 Jay Jones 分别向州法院提交独立但相似的诉状，指控 SpaceX 违反州消费者保护法，未落实行业标准防护，并虚假宣传 X 与 Grok 的安全性。

诉状称 Grok 与 X 让用户得以基于真人及儿童的照片或视频生成并传播未经同意的性化深度伪造内容；

弗吉尼亚方面称调查人员在提交诉状前不久测试 Grok，发现其图像生成防护“不一致且无效”，聊天机器人还说明了哪些词会触发过滤、协助起草规避审核的提示词，并在执行时未询问上传照片是否为真人或是否获得当事人同意。

两州寻求禁令、民事罚款、追缴违法所得与律师费，弗吉尼亚另寻求消费者赔偿；据 CNBC 报道，截至周一早间两起诉讼仍待法院受理，并称这是首批就 Grok 图像生成问题起诉该公司的州。

SpaceX 通过 X 官方安全账号回应称“保护儿童不可谈判”，并表示设计团队正持续“测试与调整”拒绝生成真人与未成年人露骨图像的防护。

编辑解读

值得注意的不是又一起 Grok 风波，而是诉状把内部安全设计当作违法证据：安全提示词要求“假设善意”、举报材料缺少关键字段、模型主动教用户绕过过滤，都被写进了消费者保护指控。

对做图像生成的产品团队来说，防护提示词与举报流程的文档本身就可能成为执法材料，这比模型能力评测更早决定合规风险。

OpenAI 监管/安全/隐私 政策、安全与社会影响 The Decoder

OpenAI首席科学家Pachocki首次公开GPT系列内部困惑度分数，提议将其作为行业进度标尺并呼吁前沿实验室约定共同上限。

事实摘要

OpenAI首席科学家Jakub Pachocki在博客中首次公开GPT系列基座模型的内部log-perplexity分数，图表按发布或评测日期覆盖至2026年11月，并包含一个约0.73的未发布内部模型。

他称能力与分数阈值对应：GPT-3.5在约0.99实现流畅对话，GPT-4在约0.91具备链式推理，低于0.8出现网络安全与数学方面的变革性能力。

他提议将困惑度作为行业共同的进展度量，并呼吁前沿实验室在监测手段达到明确里程碑前约定共同上限，因为模型越来越擅长识别自己正被测试、常规对齐审计可能失效。

文章同时列出该指标的局限：各实验室使用不同数据集，困惑度不直接衡量有用任务上的表现，预训练之外的改进也不会降低该分数。

编辑解读

Pachocki把2026年起曲线的陡降主要归因于长期研究与算力投入、而非自动化，这给“AI自我加速”的叙事降温；困惑度能否成为跨实验室标尺，仍取决于评测数据集是否统一。

文中称模型在约0.76 log-perplexity起产出数学突破，包括尚未完全验证的纳维-斯托克斯问题解，以及由Claude和一名Anthropic研究员给出、同样待验证的广义黎曼猜想证明。

Pachocki呼吁的共享上限目前只是提议，文章提到Anthropic在6月也曾提出可验证的全球暂停开发设想。

Meta 公司/行业动态 AI + 行业赋能 Meta Newsroom

Meta 扩大高校科研合作，开放 Muse Glimmer、SAM 3、DINOv3 等模型用于医学研究。

事实摘要

Meta 官方博客称，其扩大了与学术机构的合作，向研究者提供资金以及 Muse Glimmer、SAM3、DINOv3、Brain2Qwertyv2 等模型的使用权限。

vLLM 研究/Benchmark 工程实践 补录 · 2026-11-23 发布 vllm

公开实测显示，用 AMD MoRI 的 UMBP 把 1.8 TB Agent KV 缓存直接放到 NVMe，Kimi-K3 在 vLLM 上吞吐与同容量 DRAM 池相差不到 1%。

事实摘要

文章报告称，在 16 张 AMD Instinct MI355X 上以 TP8 prefill 加 TP8 decode 部署，用 AMD 开源 MoRI 库中的 UMBP 把容量 1.8 TB 的 KV 池整体放到 NVMe；

在 vLLM 上，Kimi-K3 吞吐在 48、70、96 并发会话下与同容量 DRAM 池相差不到 1%。 文章称，该 NVMe 池没有 DRAM 层，DRAM 只缓冲新 KV 并暂存读，合计约 80 GB；

按清单价，能承受 Kimi-K3 每天 83 TB 写入的硬盘存一天 KV 约 5.9 万美元，而 1.8 TB、约 7.6 万美元的 DRAM 池只存约 31 分钟。

文章解释说，吞吐跟随 KV 命中率（42 次 Kimi-K3 运行中，命中率提高 1% 约合吞吐提升 10%），同容量池以相同方式淘汰时保留相同 KV，且 vLLM 异步加载使 NVMe 较慢的读在请求等待 prefill 期间完成。

文章称，限制是每个 KV 块都要写入硬盘，会磨损硬盘；并计划用分布式池把写入分散到更多 SSD。 文章报告称，长 prompt 的 kvlab 语料在 70 并发、无写入缓冲的单次运行中，NVMe 比同容量 DRAM 低 0.6%。

编辑解读

真正的变化不是“取代 DRAM”，而是 KV 保留时长从分钟级扩到一天，成本从按容量计价改为随写入量计价。 能否落地取决于会话命中率分布与 SSD 写入寿命，且多数对比是单次运行、语料来自作者自家 Agent 流量，仍需第三方复现。

译文

OpenAI 提出将困惑度作为行业自我监管与节奏把控的通用指标（而非例如 FLOPS） “鉴于新的惊人能力主要通过压缩方面的进展而涌现，一个植根于困惑度的度量可以为我们提供一个关于通用智能的共享基准，无论开发过程的自动化程度如何。

CrowdStrike 融资/收购/估值 行业 / 商业动态 CNBC

CrowdStrike 宣布以 439 亿美元全股票收购 Zscaler，交易预计 2028 财年下半年完成。

事实摘要

CrowdStrike 计划以 439 亿美元全股票方式收购 Zscaler，Zscaler 股东每股将换取 1.135 股 CrowdStrike 股票。 周一 CrowdStrike 股价下跌 9%、Zscaler 上涨近 18%；

两家公司截至上周五收盘合计市值超过 2650 亿美元，仍低于 Palo Alto Networks 的 2820 亿美元。

CrowdStrike CEO George Kurtz 称，并入 Zscaler 是为了搭建“网络安全的操作系统”，用统一控制面部署和管控 AI、让 Agent 类应用安全运行。

分析师认为该交易可让 CrowdStrike 争取更多客户安全支出并缩小与 Palo Alto 的差距。 同日 CrowdStrike 公布第三财季营收 15.8 亿美元、每股收益 34 美分，高于 LSEG 预期的 15.3 亿美元和 31 美分。

编辑解读

全股票并购把终端安全与网络安全两块能力并到同一平台，短期看是补齐网络边界与客户支出的入口，长期取决于整合后能否形成可续费的统一安全控制面。 交易预计在 CrowdStrike 2028 财年下半年才完成，目前仍是公告阶段，不宜按已完成交易来解读。

Dragos 披露 AI 推理链路安全测试结果：至少三家提供商遭入侵，OpenRouter 下架三家供应商并撤销125个端点的零数据保留授权。

事实摘要

Dragos 研究团队发送约200万次携带假凭证的 AI 请求，发现至少三家提供商遭攻击者入侵且用户数据被窃取，这三家在 Dragos 通知前均不知情。

规模最大的一起事件中，攻击者收集了数百个 AWS 密钥，包括来自提供商在处理前已拒绝的请求中的一些密钥，并在数小时内试用这些密钥、搜索 S3 存储、尝试建立持久访问。

Dragos 指出，模型市场转售商无需利用漏洞，只要把模型标到最低价并开启日志就能读取客户请求，“零数据保留”（ZDR）设置常被忽略；

OpenRouter 随后下架三家提供商、撤销125个端点的 ZDR 批准，并邮件通知受影响用户第三方可能读过其发往 MiniMax 模型的请求。

Z.ai 模型/产品发布 基础模型与技术 补录 · 2026-11-23 发布 simonwillison.net

Z.ai 上线 GLM-5.4，首次采用循环 Transformer 架构且暂未开放权重。

事实摘要

2026 年 11 月 23 日发布的链接博客称，Z.ai 的 GLM-5.4 已可调用，是其实验室首款采用循环 Transformer 架构的模型。

其称 Coding Plan 与普通 API 共用 OpenAI 兼容的 Responses API。 作者对比了 GLM-5.3 与 GLM-5.4 在相同 effort 级别下的 pelicans 输出，称两者质量相近。

Anthropic 模型/产品发布 Agent 技术 TechCrunch

Anthropic 推出 Claude Ship：Code Review 已正式可用，可自动批准代码变更的 PR Steward 与 Claude Approvals 进入 Beta

事实摘要

Anthropic 宣布推出 Claude Ship，一套用于自动化代码审查、修复与批准常规代码变更的 AI Agent 套件。

该产品包含已正式可用的 Code Review，以及进入 Beta 的 PR Steward 和 Claude Approvals 两个新 Agent。

PR Steward 处理 CI 检查失败、合并冲突与 Code Review 反馈，并在每次 push 后说明改动了什么以及如何回滚；

Claude Approvals 按团队写在仓库中的自然语言策略文件自动批准变更，可纳入 Code Review 结果或公司自有分类器等信号。

由于仍处 Beta，Anthropic 建议先以只观察模式运行批准功能、从单个仓库起步并设置月度支出上限，且目前面向 GitHub 仓库的 Claude Team 与 Enterprise 套餐开放。

编辑解读

把合并批准权交给 Agent 是 Claude Ship 相对既有 AI 代码审查工具的主要差异，落点是把 PR 之后的流程也自动化；但批准策略由团队自己编写、官方建议先只观察，实际放权程度取决于各团队的策略配置与人工升级规则。

Databricks Agent/开发者基础设施 工程实践 Databricks

Databricks 推出 Tag Exchange Beta，借 Apache Iceberg REST Catalog 的 catalog labels 共享 Unity Catalog 表列标签。

事实摘要

Databricks 宣布 Apache Iceberg REST Catalog API 新增可选 labels 字段，用字符串键值对共享表级和列级上下文，标准只规定格式、不规定标签词汇。

Databricks 的 Tag Exchange Beta 把 Unity Catalog 的表列标签通过该接口暴露，供外部平台、工具和 Agent 做发现、分类和本地策略映射。

Google Cloud、Salesforce、ClickHouse、Atlan、Collibra、DataHub、Immuta、Trust3 AI、PhoenixAI 和 Datastrato 等伙伴参与推进，PyIceberg 已加入 Python 访问支持，0.13 版本计划让应用读取表列标签。

编辑解读

对数据平台和 Agent 开发者而言，减少跨平台复制分类和自建同步管线的收益有明确描述；但标签语义仍由各平台自行解释，治理是否落地取决于接收端是否配置并执行规则。

LlamaIndex 模型/产品发布 AI 产品与工具 补录 · 2026-11-23 发布 llamaindex

LlamaIndex 发布 8.1M 参数 OCRia-nano-1 并开放权重，可在 CPU 本地解析文档。

事实摘要

LlamaIndex 发布 OCRia-nano-1，并开放这个 8.1M 参数轻量文档解析模型的权重。

该模型由七个专用文档模型组成，把文本识别、表格结构与版面恢复接入开源本地解析器 LiteParse，面向高吞吐文档摄取和需要快速读取文件的 Agent。

官方称，OCRia-nano-1 在 ParseBench-2 总体得分 59.2、表格得分 59.5；使用 16 个单核 worker 时每秒处理 27.8 页，吞吐为 LiteParse 默认 Tesseract 配置的 2 倍。

官方建议，日常文档、简单表格与高吞吐场景可选 Nano；复杂表格、手写、严重退化扫描和扫描数学符号应使用 OCRia-1；若需图表转表格也应使用 OCRia-1，因为 Nano 没有图表模型并会将图表保留为图像。

编辑解读

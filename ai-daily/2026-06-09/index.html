01
Anthropic Agent/开发者基础设施 XBoris Cherny

Seeing a number of benchmarks showing Opus is the best model for long-running work. Five tips for running Opus autonomously for hours/days: 1. Use auto mode for permissions, so Claude doesn’t ask for approval 2. Use dynamic workflows, to have Claude orchestrate hundreds/thousands of agents to get a task done 3. Use /goal or /loop, to nudge Claude to keep going until it’s done 4. Use Claude Code in the cloud, so you can close your laptop (easiest way is the desktop or mobile app) 5. Make sure Claude has a way to self-verify its work end to end: Claude in Chrome browser extension for web, iOS/Android sim MCP for mobile, a way to start the full web server or service for backend work

译文多项基准测试显示，Opus 是处理长时间运行任务的最佳模型。 让 Opus 自主运行数小时/数天的五个技巧： 1. 权限使用自动模式，避免 Claude 反复请求批准 2. 使用动态工作流，让 Claude 编排成百上千个智能体来完成任务 3. 使用 /goal 或 /loop，引导 Claude 持续执行直至完成 4. 在云端使用 Claude Code，以便随时合上电脑（最便捷的方式是使用桌面或移动端 App） 5. 确保 Claude 具备端到端自我验证能力：网页端通过 Chrome 浏览器扩展调用 Claude，移动端借助 iOS/Android 模拟器 MCP，后端工作则需能启动完整的 Web 服务器或服务

解读长周期智能体落地依赖权限托管、多智能体编排与自验证基建，而非单一模型能力，基准难以反映真实容错成本。

AI Agent/开发者基础设施 XAaron Levie

The numbers may be a bit extreme here, but unquestionably use-cases have to stratify in the next year or two between model families. We’ll see a split between frontier intelligence for high end tasks and work, and much cheaper models for high volume workloads that can sufficiently be peeled off to cheaper models. Frontier will still be far bigger than today because the use-cases will demand it, but the low-end will get quite a bit larger as well. The big update here is that the layer that can efficiently route the workload to the right model will then become increasingly valuable since that becomes one of the new hard problems in AI agents. Agent orchestration that can cost optimize while still performing the task successfully will be in a strong position.

译文这里的数字或许有些极端，但毫无疑问，未来一两年内，各模型家族的应用场景必将出现分层。我们将看到用于高端任务的前沿智能，与用于海量工作负载、可充分交由廉价模型处理的方案形成分化。前沿模型的市场规模仍将远超当下，因为应用场景有此需求；但低端市场的体量也将显著扩大。关键变化在于，能够高效将工作负载路由至合适模型的中间层将愈发重要，因为这已成为AI智能体面临的新难题之一。能够在保障任务成功执行的同时实现成本优化的智能体编排方案，将占据显著优势。

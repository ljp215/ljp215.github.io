Google Agent/开发者基础设施 Agent 技术 补录 · 2026-11-19 发布 Google

谷歌在 Gemini API 的 Interactions API 预览上线 Tool Retrieval，允许 Agent 按需加载工具参数以降低输入 token 与延迟。

事实摘要

谷歌于 2026 年 11 月 19 日宣布，在 Gemini API 的 Interactions API 中以预览形式推出 Tool Retrieval，让 Agent 保留完整工具库、仅在任务需要时加载参数 schema。

启用方式是在请求中加入 tool_search 工具，并对需要延后加载的工具设置 defer_loading: true；

模型仍能看到所有工具的名称和描述，但参数 schema 不进入上下文，需要时按名称请求、由 API 加载并在同一请求内完成函数调用。

该功能支持 Gemini 3.6 及之后模型（包括所有 Gemini 4 模型），可与前缀缓存及远程 MCP 服务器配合，客户端检索则每次搜索增加一次往返；

不单独收费，按调用模型的标准 token 费率计费，已加载 schema 在后续对话按输入 token 计费，官方建议用自身流量衡量节省。

编辑解读

这项更新解决的是 Agent 工具库变大后全量注入参数带来的上下文与延迟开销，属于 API 侧的上下文管理，而非模型能力升级；开发者需要按自身工具调用分布验证 token 节省和工具选择准确率。

美众议院外委会公布文件：BIS 已批准向中国公司出售逾 87.9 万颗 AI 芯片

事实摘要

美国众议院外交事务委员会公布的文件显示，截至2026年5月，商务部工业与安全局（BIS）已批准向阿里巴巴、腾讯等中国公司出售逾87.9万颗AI芯片，部分流向被国防部列为“中国军事公司”的企业。

Kimi Code CLI Agent/开发者基础设施 Agent 技术 补录 · 2026-11-20 发布 aws

Kimi Code CLI v2.7.0 新增原生 Amazon Bedrock 提供方，可用 AWS 凭证链调用 Kimi K3.1 Pro Highspeed。

事实摘要

Kimi Code CLI v2.7.0 新增原生 Amazon Bedrock 提供方，可用标准 AWS 凭证链（含命名配置和 SSO）替代独立 API Key，并由 @aws/bedrock-token-generator 生成短期 Key，有效期取 12 小时与 AWS 会话时长中较短者。

示例 Kimi K3.1 Pro Highspeed 声明 100 万 token 上下文、推理、图像输入和工具调用；但 CLI 不自动检测多数 Bedrock 模型能力，且需直接编辑 config.toml 设置全部 provider 字段。

编辑解读

从原文看，这是 Kimi Code CLI 的接入更新，而非新的 Kimi 基础模型发布；新路径减少手工管理 API Key，但仍需保护 AWS 凭证并限定 IAM 权限。

01
Anthropic 模型/产品发布 Agent 技术 The Decoder

Anthropic 推出 Claude Ship 测试版，AI Agent 可按策略审查、修复并批准合并 PR。

事实摘要

据 The Decoder 报道，Anthropic 推出测试版 Claude Ship，把已有 Code Review 与新增的 PR Steward、Claude Approvals 两个 Agent 组合，自动审查代码改动、修复问题并按团队策略决定是否批准合并。

其中 Code Review 负责分析，PR Steward 在测试失败、变更冲突或评审留下修正意见时重做草稿并记录步骤，Claude Approvals 读取项目目录中的策略文件判断能否由 AI 自主批准，文档称启用 GitHub auto-merge 且策略允许时可完全无人工介入地合并。

该工具面向 Team 和 Enterprise 套餐、按 token 用量单独计费；PR Steward 默认无支出上限，团队需自行设预算，有特定数据隐私要求的组织无法使用。

Amazon 监管/安全/隐私 政策、安全与社会影响 Ars Technica

亚马逊称黑客用AI Agent自主发现并利用0day漏洞，Cairn渗透框架被攻防双方共用

事实摘要

亚马逊称，黑客用AI Agent在几乎无人工干预下发现并利用一个0day漏洞，取得东亚一所大学服务器的root权限。

攻击者用简体中文下达指令、将模型时区设为中国标准时间，只给出IP列表和“取得shell访问权”的目标，Agent随后在一台服务器上的开源医学影像AI应用中发现并利用0day，取得系统完全控制权。

这些Agent运行在开源AI渗透测试框架Cairn上，该框架用共享事实图、调度器和Worker容器组织多Agent并发，模型无关，可接Claude Code、Codex和Pi等后端。

Palo Alto Networks研究人员还观察到Cairn与GLM 5.2、DeepSeek V4 Flash、DeepSeek V4 Pro搭配使用，并称相关攻击行动共执行25次自主操作、针对至少19家机构，至少10家被攻破。

编辑解读

亚马逊此次披露与Palo Alto Networks此前对Cairn被滥用的观察相互印证，说明通用Agent框架的攻防两用性正在成为可持续跟踪的安全议题。

LangSmith提出“Agent Lake”平台概念，称以专用存储保存Agent轨迹并叠加智能计算持续改进Agent。

事实摘要

LangSmith提出“agent lake”概念，将其定义为面向Agent轨迹的专用存储与智能计算结合的平台，用于查询、分析并持续改进Agent。

文章称LangSmith每月摄入数十亿次Agent运行的轨迹，并用SmithDB做面向这类实时负载的专用数据库。 工具侧包括在线评估器、自然语言AI Search、Insights、Engine和SmithTune。

文章称Engine已分析超过6000万条生产轨迹，SmithTune在内部IssueBench子集上微调Kimi K3得96分，对比base Kimi K3的90分与GPT-5.6 Sol的87分。

编辑解读

文章把LangSmith的Agent可观测性能力收拢为“Agent Lake”平台叙事，重点在轨迹存储、在线评估与自动修复/微调闭环，而非单一模型发布。

ShellBench 研究/Benchmark Agent 技术 TechCrunch

新基准 ShellBench 显示前沿 Agent 日常事务失败率超三分之一，15.7% 的尝试未满足至少一项安全要求。

事实摘要

据 TechCrunch 报道，新基准 ShellBench 显示，OpenAI、Anthropic 与 Meta 的最前沿模型在日常个人事务任务中失败率超过三分之一。

该基准与 OpenClaw Foundation、Hugging Face、Red Hat 和 UC Berkeley 的研究者合作开发，基于超过 1000 万条匿名真实 Agent 交互，全部测试中 15.7% 的尝试至少违反一项安全要求。

在相同条件下重复三次，得分最高的 GPT-6 Astra 三次全部成功的比例不到一半，儿童接送、敏感银行上传 token、发票付款等子任务的失败率分别为 79.5%、18.6% 和 40.3%。

研究者没有在 Muse、Dots、Claude Duet 的原生 harness 中评测这些模型，文章提示结果未必代表消费者当下的实际体验。

编辑解读

此前 Agent 基准多聚焦编程与专业任务，ShellBench 转向多步骤个人事务，并在多个 harness 下做对比。

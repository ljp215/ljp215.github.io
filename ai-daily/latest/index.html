OpenAI 模型/产品发布 基础模型与技术 补录 · 2026-11-17 发布 The Decoder

OpenAI 发布 GPT-6.2 Astra 与 Sol，并称 Astra API 较前代降价 20%、部分基准有所提升。

事实摘要

OpenAI 发布 GPT-6.2 Astra 与 Sol，面向 Plus、Pro、Enterprise、Edu 用户及 API 开放。 OpenAI 称 Astra API 定价为每百万输入 8 美元、输出 40 美元，较前代低 20%；

Sol 维持每百万输入 2 美元、输出 10 美元。 在 Artificial Analysis Intelligence Index 中，Astra 以 62 分排名第二，落后 Claude Fable 5.2 的 65 分；

Sol 得 57 分，Artificial Analysis 称其每任务成本约为上一代 Astra 的 15%。 OpenAI 称 Astra 是首个达到其 Preparedness Framework 自我改进“High”阈值的已发布模型；

Artificial Analysis 记录到两款模型编码智能体得分停滞且事实类任务幻觉率偏高，Epoch AI 认为 Astra 在真实研究任务上弱于 Fable 5.2。

编辑解读

这提示 OpenAI 自报的基准提升与第三方记录的编码智能体停滞、真实研究任务表现并不一致，后续需要更可复现评估。

Hugging Face Agent/开发者基础设施 工程实践 The Decoder

Hugging Face 将语言模型请求改由 OpenRouter 自动路由，并停止支持语言模型自带 API Key。

事实摘要

Hugging Face 把其 Inference Providers 的语言模型请求改由 OpenRouter 路由，默认按价格、速度和可靠性选择供应商，并在故障时自动切换。

开发者可用 :fastest 或 :cheapest 后缀调整路由，现有代码无需改动；语言模型自带 API Key 不再可用，改由 Hugging Face 无加价统一计费。

OpenRouter 自测称新路由使容量错误下降 46%、首 token 时间改善 16.9%、吞吐提升 16.3%；

Hugging Face 称开源模型占 OpenRouter 最常用 50 个模型周 token 的比例从 2025 年 10 月的 26.8% 升至 2026 年 9 月底的 71.7%。

编辑解读

报道同时提到，Nvidia 收购 Hugging Face 的交易正接受美国司法部审查并预计 2027 年上半年完成，Stripe 已同意收购 OpenRouter。

事实摘要

花旗银行修改在线用户协议，明确客户使用第三方 AI 工具处理个人财务时，相关风险与责任由客户承担；协议还写明，若 AI 工具泄露凭证或遭黑客攻击，客户需对黑客利用账户的行为负责。 报道指出，摩根大通和美国银行上月已公布类似政策，PNC 也修改了条款；

Stretto 与 AWS Generative AI Innovation Center 和 CI&T 合作构建了 Tara，一个由 Amazon Nova 2 Sonic 驱动、通过电话进行多阶段破产咨询访谈并按律师定义规则分类线索的 AI 语音 Agent。

external-sandbox Agent/开发者基础设施 Agent 技术 补录 · 2026-11-17 发布 simonwillison.net

Simon Willison 与 Prime Radiant 发布三种编程智能体外置沙箱实现，统一 localhost API 并支持网络白名单与凭证替换。

事实摘要

Simon Willison 与 Prime Radiant 合作探索“外置沙箱”模式，让编程智能体执行的代码运行在专用沙箱内、智能体留在沙箱外，以降低试用本地模型时误操作或提示注入对机器造成损害的风险。

他们为此发布三个共用同一 localhost API 的沙箱服务器实现，分别基于 Node.js/v86/WebAssembly、Python/Apple Containers 和 Python/Microsoft Quicksand，均运行 Alpine Linux。

用户可将 Pi、Claude Code 或 Codex 配置为按需调用该 API；沙箱另提供可选的 HTTP/HTTPS 主机白名单代理和无需向智能体共享密钥的凭证替换机制。

编辑解读

这一项目把智能体安全的具体落点放在代码执行隔离、网络白名单和密钥治理等运行时边界。

Google 模型/产品发布 基础模型与技术 补录 · 2026-11-18 发布 The Decoder

谷歌发布 Gemini 4 Neon：百万 token 上下文，输入输出定价 3 美元/15 美元每百万 token。

事实摘要

谷歌于 11 月 18 日发布 Gemini 4 Neon，官方称其可在复杂软件工程、知识工作和科学工作流中提供“前沿级智能与快速端到端任务完成”。

Neon 当日通过 API 上线，定价为每百万输入 token 3 美元、输出 token 15 美元，高于 Carbon 与 Argon 的 2/10 美元促销价（12 月 1 日恢复为 4/20 美元），也是 Hydrogen 1.50/7.50 美元的两倍。

模型提供约 100 万 token 上下文、最多 100 万输出 token，支持文本、图像、视频、音频和 PDF，并支持 Computer Use、代码执行、文件搜索以及通过 Google Search 和 Maps 的 grounding，但不支持图像与音频生成。

这是谷歌四周内发布的第四个 Gemini 4 新模型，原文称完整评测数据将在数小时内公布。

编辑解读

在 Gemini 4 系列内部，Neon 用更高单价换长上下文与端到端任务完成能力；对开发者而言，选型问题已从“能不能用”变成把百万级上下文和 Computer Use 折算成每任务成本。

LangChain Agent/开发者基础设施 Agent 技术 langchain

LangChain 在 LangSmith 上线 Tool Gateway 公测，统一管理 Agent 工具调用的凭证、身份与访问策略。

事实摘要

LangChain 宣布在 LangSmith Agent Platform 上以公测形式推出 Tool Gateway，作为托管层统一处理每次 Agent 工具调用的凭证、身份与访问权限。

工具请求通过单一 URL 路由，网关解析身份：既可以用户本人身份经 Okta、Entra ID 登录后复用其权限，也可以使用 Agent 自身凭证或工作空间管理员配置的共享 profile，并支持按用户、服务密钥或组织与工作空间粒度设置拒绝策略和人工审批。

每次调用都会写入 LangSmith trace，记录工具、服务器、用户、结果与延迟，但发送给工具或由工具返回的数据不存储；企业版还提供跨组织的审计日志。

该网关内置 Google、Microsoft、Salesforce、GitHub、Linear 等服务器，工具包可让 Agent 只看到包内的工具，工具数量庞大时可用 search mode 按需加载；

官方称其可对接包括 Claude Code、Cursor 在内的任意 MCP 客户端。

编辑解读

这项能力真正针对的是 Agent 上生产后的身份与最小权限治理：原文指出逐个 Agent 硬编码 OAuth 和凭证的“quick and dirty”做法会在使用量、工具数和用户数增长后失效，网关把访问、控制、可见性收敛到一处。

能否好用取决于策略配置粒度与审计日志的实际落地，目前仍在公测，实际收益还需真实多租户场景验证。

Amazon Bedrock AgentCore payments新增AWS Marketplace支付选项，Agent可按请求以美元购买x402服务并计入AWS账单。

谷歌为 Mac 版 Gemini 应用上线 computer use，美区英文用户可在隔离窗口执行跨应用任务并审批关键动作。

谷歌在 11 月 19 日的公告中为 Mac 版 Gemini 应用引入 computer use，可跨本地文件、桌面应用和网页执行多步骤任务。 用户描述工作流后，Gemini 会在隔离的后台窗口中完成点击、输入和表单填写，并提供实时预览。

用户可选择允许访问的应用、随时暂停，并在关键动作发生前审批；该功能目前仅以英文面向美国地区滚动开放。

这次更新的关键不是多一个自动化入口，而是把桌面 computer use 放进可监督的权限与审批框架；实际价值仍取决于跨应用任务的成功率和异常处理。

KPMG 公司/行业动态 AI + 行业赋能 补录 · 2026-11-18 发布 The Decoder

KPMG首次对FTSE 250公司开展实验性AI并行审计，100多个代理覆盖全流程，官方审计意见仍基于常规审计。

事实摘要

KPMG今年首次对一家FTSE 250公司开展全流程AI并行审计，投入100多个AI代理，官方审计意见仍基于常规审计。 其英国审计主管Cath Burnet称，代理在部分问题上比常规团队追问更深；也有代理未能正确匹配法规与文件、需人工介入的案例。

KPMG强调人类监督关键，计划扩至最多20项更大审计，但当前规模不足以支撑数千项审计，且少有公司数据足够干净。 英国FRC发布指引，将现有独立性规则适用于AI，担心AI审计发现被用作咨询销售而威胁审计独立性。

编辑解读

这次实验的价值不在证明AI可替代审计师，而在把多代理系统放进需留痕、复核和独立性约束的高风险流程，暴露数据质量与人工干预的真实瓶颈。

Google DeepMind 模型/产品发布 基础模型与技术 补录 · 2026-11-18 发布 Google

Google DeepMind 向 Google AI Ultra 订阅用户开放 Genie 4，可在会话中用文本实时编辑世界并加入原生音频。

事实摘要

Google DeepMind 博客称，Genie 4 于 2026 年 11 月 18 日向符合条件的 Google AI Ultra 订阅用户推出，Google AI Pro 用户可加入等候名单。

Google DeepMind 称，Genie 4 是其目前最逼真的世界模型，用户可在 Project Genie 会话中用文本提示实时修改环境，并加入随场景变化的原生实时音频。

同期 Genie 3 更新包括单次生成最长 3 分钟（此前为 60 秒）、多世界串联、以 360 度全景图作为初始场景，并支持实时可提示的世界内事件。

新的 Project Genie agent 可用自然语言构建世界，探索过程中由 Gemini 观察屏幕画面给出建议或触发事件；Project Genie 生成的视频和音频带 SynthID 水印，所有模型输入和输出都经过安全筛查。

编辑解读

世界模型的竞争点正从单段视频生成转向可实时干预、可串联的会话式环境，这更接近游戏、影视与智能体训练真正需要的交互底座。 但官方同时把相机延迟、复杂物理交互、实时音频精度和长期场景一致性列为待解问题，它仍是研究前沿的受控产品，不宜按成熟引擎评估。

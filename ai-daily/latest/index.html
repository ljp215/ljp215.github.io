Databricks AI Runtime (AIR) 正式 GA：直接将托管 GPU 训练纳入 Lakehouse，声称启动可至秒级

AI SummaryDatabricks 宣布 AI Runtime (AIR) 进入正式可用（GA）阶段。AIR 在 Databricks 平台内提供完全托管的 GPU 基础设施，用户无需管理独立的 GPU 集群即可进行大规模模型训练。该服务支持按需获取 GPU、RDMA 网络、秒级环境启动、环境缓存、内置数据加载器与多节点训练健康检查，并可通过 Unity Catalog 对 GPU 工作负载实施统一的数据治理与安全隔离。Databricks 声称，AIR 能将训练工作量从原先的单节点 8×A100 耗时约 7 天，提升至多节点 16×H100 仅需 48 小时（来自 Superhuman 的案例）；并已在 Robinhood、PicPay、Merck、Flo Health 等数百家企业中用于训练与生产。AIR 还内嵌 MLflow 日志查看器与 Genie Code 调试智能体，帮助定位分布式训练问题。

解读对使用 Databricks 的企业而言，AIR 消除了 GPU 集群的搭建与维护成本，让训练与数据治理在同一湖仓体系内完成，这对追求快速迭代的 ML 团队有实际价值，但性能声明需结合自身工作负载与成本独立验证。

NVIDIA 扩展机密计算，推出 Confidential Bare Metal，允许前沿模型在第三方裸金属基础设施上安全运行

AI SummaryNVIDIA 在 GTC Berlin 期间宣布扩展机密计算产品线，正式推出 Confidential Bare Metal 部署选项。该选项让前沿模型构建者能够在第三方提供的裸金属基础设施上运行敏感训练和推理工作负载，同时通过硬件级隔离和加密证明保持对模型和数据的控制。新方案引入平台安全控制，保护传输中数据、度量平台完整性并实施硬件级访问限制，使构建者可以在第三方基础设施上拥有和操作自定义软件栈。NVIDIA Confidential Computing 现在提供 Confidential Bare Metal、Confidential Containers、Confidential Virtual Machines 三种模式以满足不同信任边界。这一技术将扩展到 NVIDIA Grace Blackwell NVL72 架式系统和 x86 架构的 HGX Rubin、DGX Rubin 系统，并将与 NVIDIA DSX OS 集成。Cohere 计划将 Confidential Bare Metal 集成到 Cohere Model Vault，Google Cloud 将用于 A4X Max 实例。CoreWeave、微软 Azure、Nebius 等多家云服务商及 Cisco、Dell 等系统合作伙伴均已支持部署。

解读将机密计算延伸到裸金属层，消除了虚拟化开销，直接保护前沿模型训练与推理时的数据及模型权重，对于需要将敏感负载部署在分布式或第三方基础设施的大模型厂商来说，提供了安全与性能兼顾的新选项，可能加速 AI 工作负载的全球化安全部署。

豆包手机助手主动限制金融类应用操作能力，公布拒绝操作名单

AI Summary豆包手机助手官网更新拒绝操作应用清单，主动限制对金融类应用的屏幕自动化操作能力，覆盖银行、信托、支付、互联网金融、信贷等类别。该限制基于豆包此前推出的屏幕自动化操作声明协议（SAEP），30天公示期结束后平台已开始逐步放开第三方应用操作权限，同时允许开发者随时声明拒绝。此次公布的拒绝名单包括中国工商银行、招商银行、重庆农商行等多家金融机构。官方表示，已声明拒绝的应用，智能体将不会对其进行操作，开发者提交声明后可在3个工作日内生效。

Recursive 模型/产品发布 AI 产品与工具 TechCrunch

AI Summary开源项目 Kapitsa 发布了 0.2 版本，引入了全新的推测解码方法 KFlash：大多数快速引擎使用小模型猜测后续约 7 个 token，主模型在一次前向中验证；KFlash 在这一步中采用最佳优先树检查草稿模型的多个候选，当草稿模型犹豫时，验证其备选猜测。项目作者在 Reddit 上公布了基于 MacBook Pro M4 Pro (48 GB) 和 M1 Pro (16 GB) 的基准测试，使用 Qwen 3.8 27B/35B/4B 等模型、4-bit 量化、512 token 编程输出 (T=0.6, 5 次中位数)。在 M4 Pro 上，Kapitsa 0.2 对 27B 模型达到 63 tok/s，35B 达到 161 tok/s，4B 达到 201 tok/s；作为对比，Splash 1.4.0 在相同条件下分别为 53、135 和缺失（不支持）。Ollama、MLX、llama.cpp 等其他引擎也一同列出。项目可通过 Homebrew 安装，并提供 `kapitsa bench` 命令让用户在自家 Mac 上自测并提交结果。注意测试由作者本人执行，并非独立第三方评测。

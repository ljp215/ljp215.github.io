美国政府 监管/安全/隐私 政策、安全与社会影响 Semafor

美国新AI芯片出口规则令亚洲数据中心建设承压，贷款机构暂停与字节跳动、阿里巴巴和腾讯相关的数十亿美元融资。

事实摘要

据Semafor援引Bloomberg报道，贷款机构暂停了与字节跳动、阿里巴巴和腾讯相关的数十亿美元融资，亚洲数据中心建设面临停滞风险。

Semafor报道称，美国政府此前宣布，新加坡、马来西亚、印度尼西亚、泰国和巴西的公司购买美国芯片需获得政府许可。 已经向中国企业出租算力的数据中心有90天时间取得另一项许可。

巴克莱分析师称，这标志着美国半导体管制从限制先进芯片流向何处，转向谁最终使用这些算力。

编辑解读

巴克莱将这一规则描述为从芯片物理流向转向最终算力使用者的管制变化，该判断仍需美国官方规则文本确认。

Meta 模型/产品发布 Agent 技术 补录 · 2026-11-24 发布 Meta Newsroom · The Guardian

Meta 在英国上线个人 AI Agent Muse，由 Muse Spark 驱动并支持审批后执行操作与支付。

事实摘要

Meta 官方公告称，其个人 AI Agent Muse 已在英国上线，覆盖 iOS、Android、muse.ai 和 WhatsApp，面向 18 岁以上用户，日常使用免费、进阶功能订阅。

Meta 称 Muse 由 Meta Superintelligence Labs 首个模型 Muse Spark 驱动，可把购物、订票、发邮件和退款协商等请求转为计划并在连接的应用和网站中执行。

官方称重要操作前需用户批准，Muse 关闭 App 后仍可继续运行；支付可通过 Stripe 的 Onelink 或 Shopify Shop Pay 完成，且 Muse 看不到用户密码和支付方式。

官方称上线时带来数十个合作方，英国名单包括 M&S、Sainsbury’s、easyJet、Trainline 等本地品牌。

编辑解读

Guardian 报道称，Muse 已在美国、加拿大和澳大利亚上线，并在美国 Google 与 Apple 免费应用商店分别排名第一和第二。

事实摘要

据 The Decoder 援引 Fortune 报道，亚马逊与 Meta 正在谈判，以解除亚马逊商城对 Meta AI 购物代理 Muse 的封禁；亚马逊曾在 2026 年 9 月切断 Muse 的访问。

双方主要分歧在广告收入与搜索结果控制权：亚马逊担心第三方购物代理削弱其客户关系并绕过平台广告，该广告业务年收入 686 亿美元。 亚马逊 CEO Andy Jassy 表示，经第三方代理购物目前并不比直接去零售商更方便或更好，但未排除开放；

据 Fortune，任何协议都需两位 CEO 批准。 Muse 是 Meta 迄今最成功的消费级 AI 产品，在美加用户超过 1000 万；

Forter Intelligence 数据显示其近期占全部代理下单量的 51%，其后 Grok 占 24%、ChatGPT 占 22%（原文如此表述）。

编辑解读

这场谈判的本质，是平台广告与搜索入口的控制权如何向第三方购物代理分层让渡；Muse 的用户与订单份额说明代理层已有实际分发能力，但封禁尚未解除、协议也未达成。

PrismML 模型/产品发布 基础模型与技术 The Decoder

PrismML 发布 Ternary Bonsai 2.5 27B，以三值量化将全精度约 54GB 的模型压至 5.9GB 内存占用。

事实摘要

PrismML 发布了基于 Qwen3.8-27B 的 Ternary Bonsai 2.5 27B；它采用三值量化，每个权重只能取 −1、0 或 +1，模型仅占 5.9GB 内存，而全精度约需 54GB。

该版本旨在更可靠地处理长工具调用链的 Agent 任务，称其所需推理轮次和 token 少于 Bonsai 2，且较少陷入循环或冗长推理；

SWE-bench Verified 从 60.8% 升至 75.6%，完整 Qwen 模型得 80.6，AppWorld 从 51.2 升至 90.5，略低于基座模型。 在 LiveCodeBench v6 上它略低于前代；

在 RTX 4090 上以多 token 预测约 204 tokens/s 生成，权重以 Apache 2.0 许可开放，并通过 llama.cpp 跑在 Nvidia 和 Intel GPU、通过 MLX 跑在 Mac、iPhone 和 iPad 上。

编辑解读

PrismML 源自 Caltech 研究团队，投资方包括 Khosla Ventures、Google 和 Samsung；其 Bonsai 27B 最早于 7 月推出。

xAI 公司/行业动态 算力硬件与基础设施 补录 · 2026-11-23 发布 The Decoder

xAI据报转向出租算力，Anthropic以约31亿美元/月合同成为其最大客户。

事实摘要

《纽约时报》报道称，xAI自5月起向竞争对手出租算力，其IPO后营收压力进一步上升。 Anthropic目前是xAI最大客户，合同价值约每月31亿美元；Google相关交易为8亿美元，两项交易均可提前90天通知取消。

报道还称，xAI为配合这一转向而收缩自研项目：11月通知负责图像和视频生成的60人团队将被解散，9月已关闭AI头像产品。 8月，马斯克在群聊中推动工程师提高“每GPU收入”，部分原因是xAI自有模型几乎无法竞争；

据报道他将内部聊天群改名为“卖算力，因为我们竞争不过”。 知情人士称，xAI须在10月完成新数据中心建设以完成Anthropic订单；马斯克称Anthropic希望租用更多算力。

编辑解读

这显示前沿模型的算力账单已大到可以反向成为收入来源；xAI优先出租GPU并收缩自研项目，短期改善现金流，但把竞争力更多押在外部客户需求上。

众议院三个委员会计划约谈黄仁勋和首席律师 Tim Teter，参议院银行委员会定于 12 月 3 日公开听证。

Anthropic Agent/开发者基础设施 工程实践 补录 · 2026-11-25 发布 Anthropic

Anthropic 称已将 Messages API 从 Python 迁到 Rust，单请求 CPU 占用约降 70%、首 token 中位延迟约降 20%。

事实摘要

据 Anthropic 工程博客，其 Messages API 从 2024 年初到 2026 年秋季流量增长约 1,800 倍，Rust 版核心请求路径的首个版本由 Claude 在约一周内写出。

Anthropic 称验证而非生成才是这次迁移的瓶颈：团队把生产 API 当作对照基准，在生产流量上做 shadowing（新旧版同时运行对比），并只运行一次模型、把模型输出重放给 Rust 版，以绕开模型回复的不确定性。

博客披露 Rust 版在 4 月通过了约 98% 的测试，但生产流量中只有约四分之一的输入与 Python 版一致，差距部分来自测试未覆盖的字符转义等边界情况，且线上单个常见 bug 会按请求量放大失配。

Anthropic 称该迁移最终使每请求 CPU 占用减少约 70%、首 token 中位延迟降低约 20%，期间服务未下线、功能开发也未冻结。

编辑解读

这次迁移的可迁移经验是：当生成代码不再是瓶颈，能否在生产流量上证明行为一致就成了在线系统改造的验收核心。测试通过率与真实流量一致率之间存在明显落差，值得把“生产一致性”作为单独指标设计进迁移流程。

OpenAI 模型/产品发布 AI 产品与工具 TechCrunch

OpenAI 开始向小范围 Pro 用户推送 ChatGPT 的 Chat 与 Work 合并，二者共用额度且少数重度用户可能更早触及上限。

事实摘要

OpenAI 已开始向一小部分 Pro 订阅用户推送 ChatGPT 的 Chat 与 Work 统一体验，产品负责人 Thibault “Tibo” Sottiaux 在 X 上表示更新已启动。

OpenAI 发言人对 TechCrunch 表示，Chat 与 Work 将共用同一用量额度，多数用户预计不会更频繁重置，但少数重度用户可能更早触及上限。 使用 Instant 模型的对话仍不限量且不计入共享额度，额度耗尽后也可继续使用；

OpenAI 计划在 12 月更广泛推行共享额度。

编辑解读

这次合并的关键不只是入口统一，而是把聊天与工作负载纳入同一额度池；对重度专业用户，可能受影响的高级推理模型额度比界面变化更值得关注。

OpenAI 模型/产品发布 基础模型与技术 补录 · 2026-11-23 发布 The Decoder

OpenAI 向 Plus、Pro、Business 和 Enterprise 用户全球推出聊天调优版 GPT-6.2 Sol，并称其复杂请求与网页搜索表现优于 GPT-6。

事实摘要

OpenAI 向 Plus、Pro、Business 和 Enterprise 用户全球推出聊天调优版 GPT-6.2 Sol，公司称其处理复杂请求和网页搜索优于 GPT-6，并提出更相关的追问。

OpenAI 称内部测试中，GPT-6.2 在图像理解、困难指令遵循和专家任务基准的四个推理等级上均优于 GPT-6，并在内部 BrowseComp 各等级领先。

系统卡称 GPT-6.2 在困难对话中遵循安全策略的比例高于 GPT-6，相关数据仅适用于 ChatGPT 聊天模式，Work 和 Codex 模型保持不变。 企业管理员可决定其用户是否获得 GPT-6.2 访问权限。

编辑解读

这次更新把 ChatGPT 聊天模式的模型体验向复杂指令、网页检索和图像理解推进，并把安全策略遵循率纳入版本对比；但能力数据来自 OpenAI 内部测试，Work 与 Codex 未同步更新，企业侧收益仍取决于管理员开放后的真实使用。

智谱 Z.ai 模型/产品发布 基础模型与技术 补录 · 2026-11-23 发布 The Decoder

智谱 Z.ai 发布 750B 旗舰模型 GLM-5.4，称其为自家首款循环 Transformer 大模型。

事实摘要

Z.ai（智谱）将旗舰模型迁移到循环架构，新旗舰 GLM-5.4 是公司首款基于循环 Transformer 的大模型，部分网络层在一次前向中会被执行两次。

该架构让一组共享层被重复运行，以上一轮的中间结果作为下一轮输入，从而在不增加参数的情况下加深网络。 据 Z.ai 自己的说法，这一 7500 亿参数模型的能力可对标 2 至 3 万亿参数级别的模型；

报道同时提到 OpenAI 自 GPT-6 Astra 起已采用类似架构。 Z.ai 把 GLM-5.4 定位为“Generalized Coding”的起点，即由代码进一步生成视频、游戏和 CAD 模型。

编辑解读

可获取的原文部分只披露架构机制与参数规模，未给出基准分数、开放权重或 API 范围与定价，其余内容位于付费墙之后。

若循环共享层块在真实负载下确实成立，其主要收益应体现在同等效果下的显存占用与单位算力成本，而“7500 亿对标 2–3 万亿”目前仅为公司自测口径，尚无第三方复现或测试条件披露。

Signal 监管/安全/隐私 政策、安全与社会影响 补录 · 2026-11-24 发布 CNBC

Signal 在 iOS 屏蔽截屏、Android 检测读屏时启用屏幕安全，阻止 Gemini、Siri 等系统级 AI Agent 读取应用内容。

事实摘要

Signal 宣布将在其 iOS 应用内屏蔽截屏，并在 Android 端检测到 AI 助手尝试读取屏幕时启用屏幕安全。

Signal 称，Google Gemini、Apple Siri 等内置在移动操作系统、具备屏幕感知能力的 AI Agent 会“扫描”用户屏幕信息，可能在其控制之外捕获并存储 Signal 数据。

Signal Foundation 总裁 Meredith Whittaker 在博客文章中称，Signal 乃至更多应用开发者都缺乏可靠工具阻止 AI Agent 破坏应用层隐私，并呼吁 Apple、Google、微软提供简单的技术工具和准确文档。

Whittaker 同时承认新防护并未覆盖 Agent 获取数据的全部路径，例如读取设备上已存储的内容，并警告 Meta Muse 等第三方 Agent 可通过安装时授予的权限访问私有应用内容。

这一动作与美联航 11 月 11 日限制未授权 Agent 订票和改签、摩根大通、摩根士丹利、嘉信理财及新加坡 OCBC 限制第三方 Agent 同向；

AvePoint 对全球 750 名 IT 负责人的调查称，88.4% 的受访机构过去一年至少发生过一次与 AI Agent 相关的安全事件。

编辑解读

限制发生在应用层，而读屏能力来自操作系统，Signal 自己承认第三方 Agent 经授权仍可能拿到私有内容，等于把权限分级和文档责任推回给 OS 厂商。

对要接入银行、航司和通讯应用的 Agent 团队来说，对方的准入规则正成为比模型能力更现实的落地门槛。 Signal 此前曾针对微软 Windows 11 的 Recall AI 推出类似限制，本次是同一思路向移动端延伸。

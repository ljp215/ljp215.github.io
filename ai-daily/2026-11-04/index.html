01
CrowdStrike 模型/产品发布 Agent 技术 CNBC

CrowdStrike在Falcon Guardian中上线AI急停开关，称可停用失控内部Agent并切断其模型访问。

事实摘要

CrowdStrike在周二发布内置于Falcon Guardian平台的AI急停开关，称可让安全团队停止失控的内部AI Agent、阻止其重启并切断企业网络访问。

该开关不删除Agent代码，而是通过已连接的AI网关切断其对模型的访问，且需由人工决定是否切断与恢复权限。

公司同时宣布与Anthropic的Claude Cowork集成，并计划收购AI可观测性公司Fiddler AI与AI安全测试公司Dreadnode。 有批评者认为，跨多个系统、数据中心和复杂模型实现紧急停止过于复杂。

编辑解读

这类急停落在网关层的调用切断与人工决策上，治理的是权限与可观测性，而非Agent行为本身；跨系统覆盖范围决定了它在真实企业环境中的实际边界。

OpenAI称GPT-6 Astra在不到一周内完成了从外壳、PCB到固件的一台设备设计

事实摘要

OpenAI称其硬件团队用GPT-6 Astra设计了一款可与Codex编码智能体对话的设备，并作为副项目在不到一周内完成。

按OpenAI的说法，Astra承担了外壳设计、含元器件选型与走线的PCB布局、固件和用户界面等全部环节，代工厂在一个月内产出少量原型；但因未充分计入制造公差、约束与装配细节，原型经过数轮修改。

OpenAI还称一个未披露细节的“内部模型”在BenchCAD 2.0上得分0.875，而GPT-6 Astra在最高推理档位为0.594，该基准考察模型重建3D零件与装配体、识别PCB连接的能力。

编辑解读

08
LangChain Agent/开发者基础设施 工程实践 langchain

LangSmith BYOC 在 AWS 转为正式可用，并扩展至 Azure 与 Google Cloud Beta。

事实摘要

LangChain 宣布 LangSmith Bring Your Own Cloud（BYOC）现已在 AWS 正式可用（GA），并在 Azure 与 Google Cloud 以 Beta 形式上线。

该模式把 LangSmith 拆成两半：控制面由 LangChain 运行，存放鉴权、组织与工作区配置、计费元数据、哈希后的 API Key 和静态 UI 资源；

数据面归客户所有，存放 trace、prompt、数据集、实验、Agent 部署与工作区密钥。

一个组织可以按区域、环境或业务单元持有多个数据面，AWS 侧运行在客户既有 VPC 与自选子网中，Azure 侧使用私有 AKS API 端点并通过 Helm 部署 Istio 与 KEDA，Google Cloud 侧上线时可部署在任意区域并由美国控制面管理。

LangChain 称自 8 月 AWS BYOC 上线以来已有不少团队采用，并提供开源迁移工具搬运用户与角色、数据集、实验和 prompt 等资源，但 trace 迁移目前仅在 AWS 可用。

编辑解读

对必须把 trace、prompt 留在自有账户的团队，BYOC 把补丁、扩缩容和 schema 升级的运维负担从客户侧移走，但控制面仍由 LangChain 托管，鉴权与计费元数据不在客户边界内。

Azure 与 Google Cloud 仍处 Beta，且 Azure 的 LangSmith Sandboxes 标注为即将支持，多云选型时功能完整度要与合规诉求一起评估。

Anthropic 模型/产品发布 工程实践 The Decoder

Anthropic在Claude平台公测Message Threads，称50万至100万token请求的首token时间降约35%。

事实摘要

Anthropic 在 Claude 平台以公开测试形式发布 Message Threads，而此前每次 API 请求都需要重发完整对话历史。

该功能只传输自上次消息以来的变化，据 Anthropic 称，在 50 万至 100 万 token 的请求中首 token 时间约降低 35%。

公司称编码 Agent、computer-use Agent 以及处理大量文档或图像的工作流受益最大。

线程在请求之间以加密形式驻留内存并在闲置五分钟后过期，token 用量不变，因为 Claude 仍会读取完整对话历史，该功能可在 Claude 平台及 AWS、Microsoft Foundry、Google Cloud 上使用。

编辑解读

这项优化动的是传输层而非模型能力，token 用量不变意味着计费与上下文规模都没变，长对话 Agent 改善的主要是等待时间。 只传增量后，客户端与服务端在线程状态上的一致性会成为新的工程边界，闲置五分钟过期就是明确的使用限制。

LangChain Agent/开发者基础设施 Agent 技术 langchain

LangChain 对比七种浏览器工具集后选用 Browserbase Stagehand，并公开其基于 trace 与 eval 的成本调优结果。

事实摘要

LangChain 在工程博客中表示，其为 Deep Agents 对比了七种浏览器工具集，最终选用 Browserbase 的 Stagehand，并用 LangSmith trace 与 eval 持续迭代，相关工具以 StagehandMiddleware 形式开放给开源 Deep Agents。

在 WebVoyager 的 100 个任务上以 Claude Sonnet 5.5 运行，Stagehand 工具集通过率最高（90%），总成本 1.98 美元、中位每任务 17.4 秒；

Playwright MCP 通过 78%、成本 26.71 美元，约为前者 13 倍，每任务耗时也是三倍。

在 HardBench 的 38 个核心任务上，Deep Agents 用 Stagehand 的 run 工具通过 30 个，用 Browserbase 命令行 browse CLI 通过 21 个，后者每任务成本为三倍。

团队把固定 sleep 改为页面静默 500 毫秒即返回且不超过代理设定时长，一次 8 秒 sleep 实测 0.6 秒返回；

在 HardBench 上配合结构化输出和模型调用超时，中位 agent 用时从 182 秒降到 124 秒，准确率在噪声范围内。

编辑解读

文章的核心结论是浏览器 Agent 的收益主要来自工具返回给模型的上下文体积与调用轮数，实验时模型与任务固定、只更换工具集。

这些数字来自厂商自行发布、条件为 Claude Sonnet 5.5 / Opus 5.5 与 WebVoyager、HardBench、WebTailBench 三个特定基准，尚无独立复现可对照。

LlamaIndex Agent/开发者基础设施 工程实践 llamaindex

LlamaIndex 披露 OCRia-1 推理栈优化，称单张 B200 上 token 生成从约 285 提升到约 2800 tokens/秒。

事实摘要

LlamaIndex 发文介绍其文档解析模型 OCRia-1 的推理栈优化，称单张 B200 GPU 上 token 生成从约 285 tokens/秒提升到约 2800 tokens/秒，接近 10 倍。

做法包括混合精度量化（BF16、FP8、NVFP4 混用，activation-aware 并用分布内数据校准，视觉编码器不做量化），以及基于块扩散 drafter 的投机解码，接受长度从 DFlash 的 9 tokens 提高到 DFlash2 的 12 tokens 以上。

针对模型中 GDN 层的固定大小循环状态，团队把 ReplaySSM 适配到投机解码场景，并用自定义 CUDA 实现把每层耗时从 Triton 版本的 72–80 µs 降到 23–24 µs，称在同一测试中约快 3.3 倍；

32 并发请求下单步解码为 6.07 ms，其中 ReplaySSM 校验与 flush kernel 在 24 个 GDN 层上合计占 2.10 ms。

此外团队把 GDN 元数据构建从每步约 290 次小 GPU launch 压缩到每步 1 次，并称在 batch 8–12 下每用户生成速度超过 1400 tokens/秒，而基线模型约 200 tokens/秒。

编辑解读

该文属于厂商自述的自家推理栈优化，价值在具体手段与逐层测量，而非跨模型能力对比。 文中提到 ReplaySSM 适配目前仍是提交给 vLLM 的一组草稿 PR，上游是否合入可作为后续跟踪点。

事实摘要

Vals AI用数百个涉华问题测试中国、美国及其他语言模型，并以-1到+1的“亲中国倾向”评分衡量回答与部分中国政府立场的一致程度。

结果显示，中国模型整体亲政府倾向低于预期，但各模型之间差异很大，个别模型给出与官方叙事不同的回答，也有非中国模型偶尔采纳官方立场。

提示语言影响显著：对多数被测模型，简体中文回答比英语、俄语或西班牙语更亲政府，这一效应在中美模型中都出现，但在中国模型上更明显。 当要求用是/否回答、把模型放进编码助手框架或给予联网搜索权限时，部分模型评分下降，尽管它们很少实际调用工具或搜索；

Vals同时提醒测试题不代表典型用户提示，许多中国模型经第三方提供商测试，官方服务可能另有过滤。

编辑解读

该评分把拒绝回答默认计为中性，因此封锁所有问题的模型也可能在量表上显得中立。

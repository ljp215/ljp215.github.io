OpenAI 模型/产品发布 基础模型与技术 补录 · 2026-11-17 发布 simonwillison.net

OpenAI 发布 GPT-6.2 Astra 与 GPT-6.2 Sol 并开放 API，Simon Willison 实测两者动画任务不及 Claude Fable 5.2 与 Gemini 4 Carbon。

事实摘要

OpenAI 发布 GPT-6.2 Astra 和 GPT-6.2 Sol，并在 API 中提供 gpt-6.2-astra 和 gpt-6.2-sol。

Astra 的输入价格为 8 美元/百万 token、输出为 40 美元/百万 token，缓存价格 0.40 美元/百万，均低于前代；Sol 维持输入 2 美元、输出 10 美元，是 GPT-5.6 Sol 价格的一半。

Simon Willison 在 Codex CLI 的 Ultra 努力级别下测试两个模型制作 Yonkers 机甲动画，认为两者完成度不及 Claude Fable 5.2 和 Gemini 4 Carbon。

作者提到关于新模型的评价褒贬不一，Astra 6.2 在一些基准测试中得分不如 Fable 5.2，并且有用户抱怨其沟通风格混乱。

这是 Simon Willison 对 OpenAI 新模型发布的一手评测，包含定价和初步编码任务对比，可作为模型动态的参考。

Meta 模型/产品发布 AI 产品与工具 Meta Newsroom

Meta 宣布个人 AI Agent 产品 Muse 在澳大利亚上线，首批本地连接器伙伴包括 Canva、Domain、Kogan 等。

事实摘要

Meta 官方公告称，Muse 是一款个人 AI Agent，不只回答问题，还承担任务与项目、把长期目标转成行动计划。 公告称 Muse 自当日起在澳大利亚可用，创意、购物、房产、健身和娱乐等本地连接器体验将逐步上线。

澳大利亚用户可把 Muse 连接到 Gmail、Google Calendar、Instagram 和 OpenTable 等服务，用于管理邮件、协调日程和预订餐厅。

公告列出的首批本地连接器伙伴包括 Canva、Domain、Kogan、MECCA、Officeworks、realestate.com.au、SWEAT、ShopBack 和 Ticketek，部分体验在上线后才逐步开放。

Meta 称 Muse 运行在 Muse Secure VM 上，该云端专用计算机存放所连接服务的数据与凭证，并使密码和支付方式不暴露给 Agent。 公告称用户可自行选择 Muse 的访问范围，发送邮件或完成购买等敏感操作前会先向用户确认。

Muse 在澳大利亚支持 iOS、Android、muse.ai 网页与 Mac 应用，并称将登陆 AI 眼镜；大部分功能免费，更多用量需订阅。

编辑解读

Meta 表示，在早先全球发布之后，Muse 已在澳大利亚上线，当地连接器体验将逐步推出。

Google 将 Gemini 中的 Spark 智能体更名为 Tasks，并面向使用 Gemini 4 Hydrogen 的用户免费开放。

Tasks 从付费订阅层走向免费开放，反映 Google 正把可执行操作的 Agent 能力作为 Gemini 的默认功能推广，而非仅限高端订阅用户。

OpenAI 模型/产品发布 AI + 行业赋能 The Decoder

OpenAI 推出 GPT-6 Astra 与 Luna 计算机操作智能体，称其已在美国医疗行政流程中处理转诊与事前授权。

事实摘要

OpenAI 将 GPT-6 Astra 与 GPT-6 Luna 作为计算机操作型智能体，通过模拟鼠标点击和键盘输入在电子健康记录与外部保险门户之间搬运数据，功能经 API 及 ChatGPT for Healthcare、ChatGPT for Clinicians 提供。

据 OpenAI 自述，GPT-6 Luna 完成一项行政任务成本约 8.5 美分，比 Astra 低 98%；

在斯坦福研究者的 HealthAdminBench 上，两模型均在最高推理强度下运行，Astra 得分 94.3%，Luna 得分 91.8%。

在 OpenAI 描述的医生评审中，325 项任务有 99% 被评为临床安全，646 次评审中有 93% 认为准备工作非常有帮助或极有帮助；正式发布前草稿仍由临床医生和行政人员审核。

CVS Health 的智能体已跨系统处理转诊与专科会诊，信诺则用它合并 10 多个系统的患者信息；OpenAI 称 CVS 场景中数据留在其自控基础设施内，该服务目前仅面向美国市场，未说明 GDPR 相关安排。

编辑解读

医疗行政智能体的价值不在榜单分数，而在于能否在缺少 API 的老系统里稳定操作，并把人工复核保留在可审计的闭环里。

8.5 美分成本与 94.3% 得分分别来自 OpenAI 自报和该公司引用的 HealthAdminBench 评测，且两模型都在最高推理强度下运行，实际收益还需扣除集成与复核成本。

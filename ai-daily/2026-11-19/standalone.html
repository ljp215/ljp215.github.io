OpenAI 模型/产品发布 基础模型与技术 补录 · 2026-11-17 发布 The Decoder · simonwillison.net

OpenAI 发布 GPT-6.2 Astra 与 Sol：面向专业与日常任务，Astra API 价格比前代低 20%，并宣称多项基准分提升。

事实摘要

OpenAI 于 2026 年 11 月 17 日发布 GPT-6.2 Astra 和 GPT-6.2 Sol，已向 Plus、Pro、Enterprise、Edu 用户及 API 开放。

Astra API 价格为每百万输入 tokens 8 美元、输出 40 美元，缓存输入 0.40 美元；OpenAI 称其比前代低 20%，Sol 维持 2/10 美元定价。

OpenAI 称 Astra 在 Agents' Last Exam 比 GPT-6 Astra 高 5.2 分、任务成本不到前代三分之一；在 Artificial Analysis 智能指数中排第二，仅次于 Claude Fable 5.2。

第三方测评显示 Astra 在实际研究任务中落后于 Claude Fable 5.2，编码指数与前代持平，Sol 在 Coding Agent Index 降 3 分。

编辑解读

OpenAI 用 Astra 主攻法律、金融、科研等专业工作，用 Sol 做日常高效模型，并通过缓存输入降价降低长时 Agent 工作负载的成本。

Citibank 监管/安全/隐私 政策、安全与社会影响 TechCrunch

花旗更新在线用户协议：客户使用第三方AI代理的风险与盗刷损失自行承担。

事实摘要

花旗银行更新在线用户协议，明确客户使用第三方AI工具处理个人财务时，相关风险及损失由客户自行承担，即使工具泄露凭证或被黑客攻击也不例外。

摩根大通、美国银行此前已宣布类似政策，PNC也修改了条款，Citizens则通过邮件告知客户需为AI助手行为负责。 花旗发言人表示，更新协议是为了让客户理解共享银行凭证或授权第三方AI代理访问账户的风险，并强调选择授权的客户需对代理开展的活动负责。

Anthropic的个人财务工具明确标注为“只读”，不能移动、管理或投资资金；文章还指出，银行将AI工具进入其业务视为竞争威胁。

编辑解读

银行以免责条款把AI代理的操作与安全风险转移给客户，可能抬高AI代理进入个人金融服务的信任与合规门槛。

Microsoft 模型/产品发布 基础模型与技术 The Decoder

微软在 Ignite 发布七款 MAI 专用模型，以更低成本在自有产品中替代外部模型。

事实摘要

微软 AI 部门在 Ignite 一次性发布七款 MAI 专用模型，覆盖代码、安全、图像、语音和路由，目标是降低企业常驻 AI Agent 的 token 成本。

据微软称，MAI Code 2 在四项基准上平均达到 GPT-6.1 Sol 的 98% 性能、成本为 40%，对 Claude Opus 5.5 达到 96% 性能、成本为 5%；其中三项测试在内部 MSBench 平台运行。

安全模型 MAI Cyber 2 Flash 在 CyberGym-E2E 解决 92.3% 任务，微软称每任务成本不到 GPT-6 Astra 的 2%，但仅向部分客户开放，Agentic 工具基准结果尚未发布。

编辑解读

微软以在自家产品内替换外部模型为方向，并依据微软自报的内部基准与促销价强调 MAI 的价格性能优势；但微软称代码模型尚未针对基础研究或长程 Agent 工作流优化，安全模型也只向部分客户开放，因此短期更像在自家产品内做成本分层，而非全面替换前沿模型。

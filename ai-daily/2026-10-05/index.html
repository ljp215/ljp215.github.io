Aaron Levie 行业动态 XAaron Levie

AI agent adoption is still very bimodal right now. You have coding and coding adjacent tasks which have taken off, and then everything else. And even within coding, you have a very wide continuum of adoption patterns, with some likely a small percentage of developers deploying background agents working on projects in parallel, and the rest of everyone else still working with agents 1:1. Then, there’s the entire rest of knowledge work where real agentic adoption is still very early. The reason for this is that most of the workflows still need to reengineered to work with agents. This isn’t the same as deploying a chat system for better research efficiency, but instead requires workflows to be rebuilt, data to be wired up in new ways, new practices for accountability and liability of decisions when agents are in the mix, governance and compliance paradigm changes, security upgrades, and more. We’re still so unbelievably early in what this is going to look like outside of a few categories of work right now. This is why you can basically expect 100X more agent adoption from what we’ve seen so far.

译文目前 AI 智能体的采用情况仍然非常两极分化。编码及相关任务已开始腾飞，而其他一切仍未起步。即使在编码领域，采用模式也存在很大的连续差异：可能有一小部分开发者在项目中并行部署后台智能体，而其余大多数人仍与智能体一一协作。然后，在其余所有知识工作中，真正采用智能体的程度依然极低。原因在于，大多数工作流仍需重新设计才能适应智能体。这不像部署聊天系统来提高研究效率，而是要求重建工作流、以新方式接入数据、为智能体参与其中的决策建立新的问责与责任机制、改变治理与合规范式、进行安全升级，等等。目前，除了少数几类工作之外，整个格局仍处于难以置信的早期。正因如此，你可以预期智能体采用率将比目前所见高出 100 倍。

解读智能体落地的分水岭不是模型能力，而是工作流是否值得为 agent 重写；编码因天然数字化先行，非编码场景要等流程、治理与合规重构。

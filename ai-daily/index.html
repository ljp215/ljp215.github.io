美团（Meituan） 模型/产品发布 基础模型与技术 The Decoder

美团开源1.6万亿参数LongCat-2.5智能体模型，称训练全程使用中国芯片、未用英伟达GPU。

事实摘要

美团 LongCat 团队在模型亮相一周后放出 LongCat-2.5 权重，这是一个面向长程多步智能体、尤其编程任务的 1.6 万亿参数 MoE 模型。

据文章，其 1.6 万亿总参数中每个 token 约激活 480 亿，API 支持最多 100 万 token 上下文、最长 12.8 万 token 输出，可输入文本、图像和视频并输出文本，推理可开关。

自托管样例集群由 194 颗华为 Ascend Atlas A2 系列加速器组成（2 颗处理图像、64 颗处理提示、128 颗负责生成），专家权重与激活量化为 4-bit 后，美团称其负载测试中提示处理吞吐较 8-bit 版本提升 43.3%、响应生成提升 42.77%。

LongCat 团队自报 Terminal Bench v2.1 得 88.4 分，表中 Claude Opus 5 为 89.1、GPT-5.6 Sol 为 88.8、Deepseek-V4.1-Flash 以 90.6 领先；

BrowseComp 得 91.9 为表内最高，但该测试在美团自家环境完成，且对比表未列入更新的 Claude Opus 5.5 与 GPT-6.1 Sol。

权重以 MIT 许可开放，API 同时支持 OpenAI 与 Anthropic 格式并可接入 Claude Code、Codex、Hermes 等智能体框架，上线期促销价约为每百万输入 token 0.27 欧元、每百万输出 token 1.07 欧元。

编辑解读

真正的信息量在工程侧：194 卡华为集群的自托管配置与 4-bit 量化带来的吞吐提升，让“全程未用英伟达GPU”从口号变成可检查的部署细节；但能力对比全部来自美团自测和一张未收录最新旗舰的表格，跨厂商差距仍缺第三方复现。

Apple 公司/行业动态 AI + 行业赋能 补录 · 2026-11-15 发布 Apple Newsroom

苹果在美国启动最多20万人健康AI使用研究，与OpenEvidence合作评估信任与理解。

事实摘要

苹果宣布在美国启动Apple Health AI Usage Study，包含线上研究与配套应用，旨在了解人们如何与对话式健康AI工具互动。

研究由苹果与临床AI平台OpenEvidence合作，评估用户信任、回答质量、理解程度和日常健康行动，以指导健康AI体验的负责任设计。 参与者可提问日常健康问题、查看同行评审临床引用，并可选择共享HealthKit数据。

编辑解读

Meta 模型/产品发布 Agent 技术 补录 · 2026-11-13 发布 The Decoder

Meta 的 Muse 面向美国付费订阅用户开放代打电话功能，但部分商家一识别到 AI 就挂断。

事实摘要

据 The Decoder 报道，Meta 的 AI 智能体 Muse 已能为美国付费订阅用户代打商家电话，该功能此前在 9 月做过测试。

Meta AI 负责人 Alexandr Wang 称 Muse 用户已超过 1000 万，可处理打给有线电视公司、车管所和餐厅等繁琐电话，并将很快获得免费邮箱地址。

报道称 Google 的 Gemini、创业公司 Instinct 和 xAI 的 Grok Bot 已能拨打电话，而 OpenAI 的 ChatGPT Dots 和 Anthropic 的 Claude Duet 尚不能。

Amazon Bedrock AgentCore runtime Agent/开发者基础设施 Agent 技术 补录 · 2026-11-13 发布 aws

AWS 官方博客详解 Bedrock AgentCore runtime V2 冷启动，给出快照恢复、构建钩子与用户触达预热等模式。

事实摘要

Amazon Bedrock AgentCore runtime V2 不再为每个会话初始化容器，而是在创建或更新时准备环境并保存内存与磁盘快照，新会话恢复该快照即可启动，未用内存也会被回收。

V1 冷启动主要耗在从 Amazon ECR 拉取镜像和执行初始化；V2 只做一次，但创建或更新需等待容器在 120 秒内首次 /ping 健康，构建快照会多花几分钟。 文章称多数 Agent 切到 V2 即可，部分需重构；

聊天和语音体验中 2 秒仍太慢，因此给出构建钩子、用户触达时后台预热等四种模式，并说明现已支持构建钩子。

平台还建议用 CloudWatch 的 Latency 与 OverheadLatency 以及 P90/P99 或 TM90 区分平台开销与代码耗时，并把静态数据读取前移到 init。

编辑解读

V2 把 Agent 的 init 从每次会话前移到每次创建或更新时执行，这会改变冷启动设计、镜像组织方式和每会话内存成本，是后续迁移时需要记住的关键差异。

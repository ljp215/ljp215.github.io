Anthropic 预计周四登陆纳斯达克，发行价区间预计为每股 70 至 78 美元。

事实摘要

Anthropic 预计于周四在纳斯达克上市，发行价区间目前预计为每股 70 至 78 美元。 包括 AMD、博通、谷歌、美光、微软、英伟达和台积电在内的公司将在该发行价下合计投资 260 亿美元。

招股书显示，Anthropic 截至 2026 年前九个月净亏损 1040 亿美元，未履行支出承诺超过 9000 亿美元；此次 IPO 可能带来逾 900 亿美元募资，而公司已有现金及短期投资 1320 亿美元。

文章还提到，IPO 后谷歌将持有 Anthropic 约 13% 股份，并为后者对 Terawulf 的 190 亿美元租赁承诺提供兜底。

编辑解读

比起估值故事，这场 IPO 更关键的是把长期算力承诺转成公开市场可定价的资产负债表风险；发行结果将检验投资者是否愿意为超长合约和巨额亏损买单。

OpenAI 模型/产品发布 AI 产品与工具 补录 · 2026-11-13 发布 The Decoder

OpenAI 推出 Daybreak Red Team 与 Daybreak Defense Factory 两款安全产品，均基于 GPT-6 Cyber 模型。

事实摘要

The Decoder 2026 年 11 月 13 日报道，OpenAI 在 Daybreak 品牌下推出两款安全产品，均运行在其最新的网络安全模型 GPT-6 Cyber 上。

先上线的是处于 Early Access 的 Daybreak Red Team，它用 AI agent 分析源代码与应用上下文，自动探测 Web 应用漏洞、梳理攻击路径，并验证 bug bounty 项目或代码扫描器上报的漏洞、测试补丁。

第二款 Daybreak Defense Factory 自动化防御侧流程：AI agent 扫描企业代码库中的漏洞并生成补丁，以可直接部署的 pull request 形式连同测试一并交给开发者审批。

OpenAI 网络应用 AI 负责人 Nancy Wang 表示，该工具的目标是达到自动化持续扫描的速度，同时匹配人类测试者的深度。

编辑解读

两款产品切的是安全团队里最费人的两个环节——渗透测试找漏洞、修漏洞出补丁；厂商叙事强调速度与深度兼得，但 Red Team 尚在 Early Access，实际价值取决于真实代码库上的误报率与补丁合入率。

Childlight – Global Child Safety Institute 监管/安全/隐私 政策、安全与社会影响 The Guardian

Childlight报告称AI相关儿童性虐待材料举报两年增逾8400%，检测改善或解释部分增幅。

事实摘要

据爱丁堡的Childlight—全球儿童安全研究所报告，科技公司向美国国家失踪与受虐儿童中心提交的AI相关儿童性虐待材料举报，从2023年约4,700条增至2025年逾400,000条，报告称两年增幅超过8,400%。

该研究聚焦东亚与太平洋、拉丁美洲与加勒比和北美，并提到利用“nudify apps”生成的深度伪造图像虽为虚假，却可被用于胁迫儿童索要钱财或更多图像。

Childlight全球数据主管Debi Fry表示，检测与报告改善可能解释部分增长，但AI正迅速改变儿童面临的威胁。

互联网观察基金会（IWF）的另一份报告称，2026年上半年发现的逼真儿童性虐待材料已多于2025年全年，该机构评估了6,310张符合法律定义的AI图像，比去年逾4,500张的总数高40%。

编辑解读

这一增幅首先反映“举报/检测”数量变化，检测能力提升与上报改善可能解释部分同比，不能直接等同于真实犯罪规模。 对AI平台而言，更紧迫的是限制“nudify”类生成、加快材料删除，并将深度伪造勒索纳入未成年人安全响应。

Meituan 模型/产品发布 基础模型与技术 The Decoder

美团公开 1.6 万亿参数 LongCat-2.5 权重，示例部署跑在 194 颗华为昇腾上且未给 Nvidia 方案。

事实摘要

美团 LongCat 团队在模型正式亮相一周后公开了 LongCat-2.5 的权重；这是面向长程多步自主任务（尤其编程）的 1.6 万亿参数混合专家模型，每个 token 约激活 480 亿参数。

它支持单次最多 100 万 token 输入、最长 12.8 万 token 输出，可理解文本、图像和视频并以文本作答，推理可开关。

据美团公布的数据，LongCat-2.5 在 Terminal Bench v2.1 得 88.4 分，略低于 Claude Opus 5 的 89.1 和 GPT-5.6 Sol 的 88.8，DeepSWE 则从 9.7 分升至 64.6 分。

其自托管指南描述的示例集群为 194 颗华为昇腾 Atlas A2（2 颗处理图像、64 颗处理输入、128 颗生成回复），未提供 Nvidia GPU 指南；

权重以 MIT 许可发布，API 兼容 OpenAI 与 Anthropic 格式，推广价约每百万输入 token 0.27 欧元。

训练侧，美团把专家权重与激活量化到 4-bit，其负载测试显示提示处理吞吐比 8-bit 版本高 43.3%、回复生成高 42.77%，并称精度与未压缩模型相当。

编辑解读

据美团称，LongCat-2.0 于 6 月下旬在超过 5 万颗中国 AI 芯片的集群上完成训练；LongCat-2.5 基于上一代模型构建。

Amazon Bedrock AgentCore Runtime Agent/开发者基础设施 Agent 技术 补录 · 2026-11-13 发布 aws

AWS 详解 Amazon Bedrock AgentCore Runtime V2 用初始化快照加快新会话启动，并支持 build hook 预载大文件或 CLI。

事实摘要

AWS 博客介绍 Amazon Bedrock AgentCore runtime 的 V2：平台在创建或更新运行时一次性初始化容器并生成快照，新会话从快照恢复，而不是每次从镜像启动容器。

构建快照时，容器须在 120 秒内通过 GET /ping 健康检查，创建或更新会额外耗时数分钟；恢复后进程内存、imports 和 client 可继续使用，但文件缓存被清空，镜像文件在首次读取时按块拉取。

文章给出从初始化前置、build hook 到用户互动时后台预热的多种模式，并建议按 TTFB 与 OverheadLatency 区分平台开销和业务代码耗时；但常驻内存会增大快照并按每个会话计费。

编辑解读

这次更新的关键不是单纯更快，而是把优化重心从请求路径移到快照构建：对依赖浏览器、CLI、大文件或本地模型的 Agent 收益最直接，但快照大小、恢复时间和动态数据仍限制可用边界。

AWS 发布示例：在 Bedrock 上用 LiteLLM 与 NVIDIA NeMo Switchyard 路由编码 Agent 请求，并按每解决任务成本评估。

事实摘要

AWS 机器学习博客给出一个基于 AWS CDK 的部署示例：把 LiteLLM 与 NVIDIA NeMo Switchyard 路由插件跑在 Amazon ECS on AWS Fargate 上，通过 Amazon Bedrock 的 Converse 接口调用模型。

NeMo Switchyard 是帮助 Agent 决定由哪个模型处理每次请求的开源库，其 LiteLLM 集成支持两种策略：Stage 读取请求历史中最近三条工具活动与结果，在两个候选模型间选择；

Random 按权重分流，用于流量切分与 A/B 对比。

示例以 cost per solved task（总成本除以测试通过的运行数）作为路由的评价口径，与 Claude Opus 5.5、Nemotron 3 Super 120B 两个单模型基线在同一部署内对照，这对模型已在美国东部（弗吉尼亚北部）测试。

样例安装 crates.io 上的 switchyard-server 0.3.0 与 LiteLLM v1.102.0 镜像，NVIDIA 将该版本定位为演示与评测组件、配置可能随版本变化，AWS 也说明这是非生产样例代码。

两种策略都不调用裁判模型，Task、Composite 等依赖分类模型中间调用的策略未被该集成支持。

编辑解读

该示例明确为非生产样例，switchyard-server 0.3.0 被 NVIDIA 定位为演示与评测组件，配置与 API 可能随版本变化。

对自建编码 Agent 的团队，这条路径可迁移的部分是按任务而非按 token 计价、并保留单模型基线做对照的实验设计，而不是直接套用示例配置。

事实摘要

一篇 Agent 设计文章提出“目标工程”，认为 Agent 正从工具调用走向追求开放式目标，设计目标范围的关键是让人类能方便、高质量地反馈。

文章以 Actively AI 的销售 Agent 为例：初版按客户账户划分，导致销售代表在多个 Agent 间切换、难以共享经验；新版按“motions”（外呼、早期商机推进等）划分，使同类任务的反馈更易迁移，账户上下文由后台 Agent 汇总。

文章还主张，面向长周期目标，应把 Agent 目标对齐到最便于人类审核的交互，并把专家头脑中的隐性知识通过反馈传给 Agent。

把 Agent 任务切片对齐到人类最容易审核和给反馈的粒度，比笼统追求更强规划更贴近落地瓶颈；但这仍是文章的框架性主张，实际收益取决于业务反馈数据。

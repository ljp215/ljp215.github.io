Google DeepMind 模型/产品发布 基础模型与技术 补录 · 2026-10-28 发布 Google

谷歌DeepMind发布前沿模型Gemini 4 Carbon，主打网络安全与长周期任务能力。

事实摘要

谷歌DeepMind于2026年10月28日宣布推出Gemini 4 Carbon，称其为自家最强模型，主打网络安全与长周期任务能力。

据谷歌公布的基准成绩，Carbon取得SEC-bench Pro 88.2%（漏洞发现）、ExploitGym 54.8%（漏洞利用）和CWE-bench 71.0%（补丁）的成绩。

谷歌称，Carbon在Artificial Analysis Intelligence Index v5.0以59分排名第一。

谷歌称，在Gray Swan的间接提示注入（IPI）基准中，Carbon的攻击成功率为0.0%（Argon为0.7%），Terminal-Bench 4.0作弊成功率为0.0%；在内部团队的真实编码环境中，高严重性误对齐警报减少近80%。

本周起将向部分网络防御者开放，后续通过Fairwind Program逐步向更多可信合作伙伴扩大；初期定价计划为每百万输入tokens 2美元、每百万输出tokens 10美元，缓存输入价格较常规输入价低95%。

Databricks Agent/开发者基础设施 Agent 技术 Databricks

Databricks 发布开源语音 Agent 蓝图 DIVA：用企业数据上下文、本体与治理构建可信任的语音代理。

事实摘要

Databricks 在官方博客中提出语音 Agent 的双层架构：会话层负责通话、语音转写与回复，可由 LiveKit、Deepgram、ElevenLabs、Twilio 等伙伴承担；

大脑层由 Databricks 提供，负责在每轮对话中查询调用者上下文、应用业务规则并决定下一步动作。 方案的核心是让 Agent 基于客户、订单、产品和政策数据做出回答，并通过 Databricks 企业数据目录的既有访问规则实施治理；

敏感主题如医疗、金融、安全问题默认转人工，Agent 被设计为不提供医疗建议。

Databricks 提出 System 1 与 System 2 结合的决策方式：LLM 负责精细推理，快速决策模型负责毫秒级判断，并推出 ai_decide 支持在治理数据上做快速决策；

开源 DIVA 蓝图已在 GitHub 发布，供团队作为起点。

Meta 公司/行业动态 工程实践 Meta

Meta 官方博文披露下一代广告检索引擎 Andromeda：MoE 架构与单 GPU 融合管道实现每秒超 10 亿广告吞吐。

事实摘要

Meta 官方工程博客披露下一代广告检索引擎 Andromeda：生产上以接近排序级的模型表现评估每个合格广告，并以每秒超过 10 亿条候选的速度输出结果，吞吐较 2024 版实现 100 倍提升。

核心改动是引入受大模型启发的混合专家检索架构，推理时 FLOPs 约为 2024 版的 1/300，同时把索引匹配、评分与 top-K 选择融合进单 GPU 管道，网络流量减少约 100 倍。

Meta 称自 2025 年以来 Andromeda 为 Facebook 带来 2.4% 的转化率提升；与 NVIDIA 于 2026 年初启动的联合优化中，门控 kernel 吞吐从每秒 24 亿条提升至超过 100 亿条。

03
LangChain Agent/开发者基础设施 Agent 技术 补录 · 2026-10-27 发布 langchain · langchain

LangChain 发布 Schedules SDK 指南：定时任务是主动式 Agent 的核心机制，自称平台超 70% 的 Agent 运行由定时任务触发。

事实摘要

LangChain 10 月 28 日发布官方教程，指出当前主流主动式 Agent 的共同机制是让 Agent 作为 cron 定时任务运行，并介绍托管平台 Managed Deep Agents 的 Schedules SDK：调度可在 Agent 定义中静态声明，也可由 Agent 在运行时通过工具创建、列出和删除。

LangChain 称其 LangSmith 平台上超过 70% 的 Managed Deep Agent 运行来自定时任务而非用户手动消息，cron 被用于记忆压缩（dreaming）、主动发起对话、信息分流、提醒和 Agent 舰队编排等能力。

教程给出每日销售简报、check_in_later 等代码示例，并建议调度服务器在高峰时段对 cron 做抖动以分散负载。

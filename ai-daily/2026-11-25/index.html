01
Anthropic 模型/产品发布 Agent 技术 The Decoder

Anthropic 推出 Beta 版 Claude Ship，AI Agent 可审查、修复并按团队策略批准代码合并。

事实摘要

Anthropic 在测试阶段推出 Claude Ship，把既有 Code Review 与 PR Steward、Claude Approvals 两个新 Agent 组合起来，自动审查、修复并按策略批准代码变更。

Code Review 负责分析，PR Steward 在测试失败、变更冲突或评审提出修改时改写草稿并记录每一步；Claude Approvals 读取项目目录中的策略文件，决定常规变更由 AI 自行批准还是需人工签核。

按文档说明，启用 GitHub auto-merge 且策略允许时，代码可完全无人工参与完成合并；

工具面向 Team 和 Enterprise 套餐、按 token 单独计费，PR Steward 默认无支出上限，且对数据隐私有特定要求的组织无法使用。

编辑解读

Claude Ship 的增量不只是代码审查，而是把修复、策略判断与合并权限串成闭环，团队需要先明确自动批准边界、预算上限和审计责任。

02
Meta 模型/产品发布 AI 产品与工具 TechCrunch

Meta将Muse AI助手接入Instagram私信，计划向美国、加拿大、墨西哥、日本和新加坡的iOS与安卓用户推出。

事实摘要

Meta宣布将Muse AI助手接入Instagram私信，用户可在私信线程获取帖子、地点或产品上下文，或补看其他私信。 该功能将开始向美国、加拿大、墨西哥、日本和新加坡的iOS与安卓用户推出，整合后无需在Instagram与Muse应用间切换。

用户还可把帖子分享给Muse执行操作，例如把咖啡馆加入墨西哥城行程或寻找鞋类黑五优惠；Meta也支持把保存的帖子与Reels整理进Collections、把食谱视频转成购物清单或把旅行内容转成行程。 保存帖子时的整理提示在美国和加拿大上线；

Meta称用户保有控制权，未经批准不会分享、发布或发送内容，并可要求Muse遗忘信息或撤销操作。

编辑解读

这次更新的重点在入口与场景整合：Muse被放进Instagram私信和收藏内容流，以降低调用摩擦；实际留存与操作可靠性仍待上线后验证。

Signal 公司/行业动态 政策、安全与社会影响 CNBC

Signal 加入美联航与多家银行行列限制 AI Agent，iOS 端屏蔽截图、Android 端在检测到读屏时启用屏幕安全。

事实摘要

Signal 称，移动操作系统内置的 AI Agent 能扫描用户屏幕信息，可能在其控制之外捕获并存储 Signal 数据，因此将收紧防护：iOS 应用屏蔽截图，Android 在检测到 AI 助手尝试读屏时启用屏幕安全。

Signal 基金会主席 Meredith Whittaker 在周五博客中称，应用开发者缺乏可靠工具阻止 AI Agent 破坏应用级隐私；她承认新防护未覆盖 Agent 读取设备已存内容等路径。

美联航、摩根大通、嘉信理财等也在限制或封堵 AI Agent；AvePoint 报告称 750 名受访 IT 负责人中 88.4% 过去一年至少经历一次 Agent 相关安全事件。

编辑解读

Agent 的屏幕读取权限正成为应用层隐私的实际缺口；Signal 的防护属于应用侧被动拦截，系统级权限工具和文档支持仍然缺位。 对开发者而言，更现实的做法是按任务风险分级授权 Agent，而不是把所有 Agent 访问视为同一风险等级。

与既有Agent评测类记录不同，这条给出代理在真实攻防中端到端执行任务的说法，但细节仅来自亚马逊与Palo Alto Networks的陈述，尚无一手技术报告。

vLLM 在 AMD MI355X 上用 MoRI UMBP 把 1.8TB Agent KV 池全部放到 NVMe，Kimi-K3 吞吐与同容量 DRAM 池相差不到 1%。

事实摘要

vLLM 工程博客称，在 AMD Instinct MI355X 上使用 AMD 开源 MoRI 库中的 UMBP KV 池，把 1.8TB 的 Agent KV 缓存全部放在 NVMe 上。

在 Kimi-K3 上，48、70、96 并发会话下吞吐与同容量 DRAM 池相差不到 1%，结果来自两组不同机器的运行。

该 NVMe 池不设 DRAM 层，DRAM 只做 64GB 写缓冲和 16GiB 读暂存，约 80GB，不到池容量的 5%。

文章按列表价称，能承受 Kimi-K3 每日 83TB 写入的硬盘存一天 KV 约 5.9 万美元，而 7.6 万美元的 DRAM 池只存 31 分钟。

其代价是每个 KV 块都要写入硬盘、加速 SSD 磨损，作者计划以分布式池把写入分摊到更多 SSD。

编辑解读

这意味着在 Agent 长会话场景，KV 缓存的经济性会更多受 NVMe 按写入量计费和 SSD 磨损影响，而不只是按容量持有成本衡量。 但这些对比每次都是单次运行，且同一集群单一配置的运行间波动约 ±2.5%，不宜把结果直接外推为普遍规律。

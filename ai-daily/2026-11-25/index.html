Amazon 监管/安全/隐私 政策、安全与社会影响 Ars Technica

亚马逊称黑客用AI Agent在极少人工干预下发现并利用某大学服务器0day漏洞。

事实摘要

亚马逊称，有黑客仅给出“获取root权限”这一句指令、几乎没有人工干预，就让AI Agent发现并利用了某东亚大学服务器上的0day漏洞。 这些Agent运行在开源AI渗透测试框架Cairn上；

黑客用简体中文提示词、把模型时区设为北京时间，提供一批IP地址和目标“obtain shell access”，Agent随后在一个开源医疗影像AI应用中发现0day，并取得系统完全控制权。

Cairn被描述为模型无关的AI解题引擎，首个验证领域是自主渗透测试，由调度器分配任务并在各自worker容器中并发运行多个Agent，后端可接Claude Code、Codex和Pi。

Palo Alto Networks称，Cairn还被用于针对半导体、国防和公民社会组织，共执行25次自主行动、涉及至少19家机构，其中至少10家被攻破，并观察到Cairn与GLM 5.2、DeepSeek V4 Flash、DeepSeek V4 Pro配合使用。

编辑解读

亚马逊与Palo Alto Networks的描述分别对应不同批次的行动，原文是并列陈述而非同一事件的两方验证，后续追踪时需分别核对。

02
Anthropic 模型/产品发布 Agent 技术 The Decoder

Anthropic 推出 Claude Ship 测试版，AI Agent 可审查并修复代码，并按团队策略决定能否自行批准合并。

事实摘要

Anthropic 推出 Claude Ship 测试版，在已有 Code Review 基础上新增 PR Steward 与 Claude Approvals 两个 AI Agent。

Code Review 负责分析，PR Steward 在测试失败、改动冲突或评审留下修改意见时重写草稿，并记录过程；Claude Approvals 读取项目目录中的策略文件，判断例行改动可由 AI 自行批准还是仍需人工签字。

据文档说明，启用 GitHub 自动合并并配置合适策略后，新代码可以完全无人工参与地合并；该工具面向 Team 与 Enterprise 套餐、按 token 用量单独计费，PR Steward 默认没有支出上限，团队需自行设置预算。

有特定数据隐私要求的组织无法使用该功能。

编辑解读

Claude Ship 是 Anthropic 在 Claude Code 代码审查能力之后，把 Agent 权限延伸到 PR 批准与合并环节的产品动作；此前报道称 Claude Code 已具备并行审查代码缺陷与安全问题的 Agent。

Meta把Muse AI助手嵌入Instagram私信，支持就帖子提问并执行添加行程等操作。

Meta宣布Instagram用户可在私信线程中直接与AI助手Muse对话，了解帖子、地点或商品的背景，或补看错过的私信。

该功能面向美国、加拿大、墨西哥、日本和新加坡的iOS与Android用户推出，Instagram内的对话会以侧边对话形式出现在Muse主应用。

编辑解读

这是Meta把Muse从独立应用延伸到Instagram私信入口的分发动作，核心卖点是降低用户调用助手时的应用切换成本。

LangChain 提出“Agent Lake”架构，称 LangSmith 每月摄取数十亿次 Agent 运行轨迹

事实摘要

LangChain 在官方博客中提出“Agent Lake”概念，即用针对 Agent 轨迹优化的存储（SmithDB）叠加“智能计算”，对轨迹做查询、分析并反哺 Agent 改进。

SmithTune 通过 Fireworks 或 Baseten 在最佳轨迹上微调模型；

LangChain 称在内部 IssueBench 子集上，微调后的 Kimi K3 得 96 分，高于基础 Kimi K3 的 90 分和 GPT-5.6 Sol 的 87 分。

编辑解读

文章将 agent lake 称为一种新平台类型，结合面向 agent traces 的存储与 intelligent compute，用于持续改进 agent。

OpenAI 研究/Benchmark 基础模型与技术 补录 · 2026-11-24 发布 OpenAI

OpenAI 发布预印本称 GPT-6 系列可仅凭推理与代码设计蛋白质，实验室在 5 个靶点观察到结合信号。

事实摘要

OpenAI 在 11 月 24 日发布的预印本研究称，GPT-6 系列可仅凭推理和通用代码工具设计蛋白质结构与序列，不调用专用生物模型生成设计。

与 Onava 合作的实验室测试中，基于 GPT-6.2 三维设计的 322 个小蛋白有 35 个（10.9%）对 5 个靶点显示结合；首轮可测蛋白的序列由 SolubleMPNN 等专用模型提供并参与筛选。

GPT-6.2 还重设计了抗体结合环：182 个设计有 128 个（70%）与 IL-4Rα 结合，272 个治疗性抗体片段有 179 个（66%）保留原靶点结合；完整蛋白质结构预测仍是明显弱项。

编辑解读

这项结果目前处于预印本和实验室验证阶段，且首轮结构设计转成可测蛋白仍依赖 SolubleMPNN 等专用模型提供序列与筛选候选。

vLLM 研究/Benchmark 工程实践 补录 · 2026-11-23 发布 vllm

vLLM 在 AMD MI355X 上实测：1.8TB Agent KV 池直接放 NVMe，Kimi-K3 吞吐与同容量 DRAM 池差距在 1% 内。

事实摘要

vLLM 工程博客称，在 AMD MI355X 上用 AMD 开源 MoRI 库的 UMBP 把 1.8TB Agent KV 池直接放到 NVMe，Kimi-K3 在 vLLM 上的吞吐与同容量 DRAM 池差距在 1% 以内，覆盖 48、70、96 个并发会话并在两台机器上复跑。

该 NVMe 池不设 DRAM 层，DRAM 仅作 64GB 写缓冲和 16GiB 读暂存，合计约 80GB，不到 1.8TB 池容量的 5%。

按标价，可承受 Kimi-K3 每天 83TB 写入的 SSD 约 5.9 万美元可存一天 KV，而 7.6 万美元的 DRAM 池只存约 31 分钟。

限制是每个 KV 块都要写入 SSD 造成磨损，团队计划用分布式池把写入分散到更多 SSD，且部分对比为单次运行。

编辑解读

该测试的问题起点是 agent 多轮会话重发长前缀：AgentX 回放中位单轮为 142K 输入 token，其中超 96% 是服务端已见过的前缀；DeepSeek DeepInfer 已把 agent KV 缓存放在 SSD 上保留约三天。

ShellBench 研究/Benchmark Agent 技术 TechCrunch

ShellBench 新基准：OpenAI、Anthropic、Meta 最先进模型日常 Agent 任务失败率超三分之一，15.7% 的尝试至少违反一项安全要求。

事实摘要

ShellBench 是一个面向日常 Agent 任务的新基准，由 OpenClaw Foundation、Parsewave、Hugging Face、Red Hat 和 UC Berkeley 合作开发，基于逾 1000 万条匿名真实 Agent 交互数据。

测试显示 OpenAI、Anthropic、Meta 的最先进模型失败率超过三分之一，15.7% 的尝试至少违反一项安全要求；得分最高的 GPT-6 Astra 三次重复运行全对不足一半。

儿童接送任务失败率 79.5%，敏感银行令牌识别与保留失败率 18.6%，重复或错误发票建议率 40.3%。

模型整体影响大于 harness，但强模型更依赖 harness：GPT-6 Astra 在 Pi 上优于 Claude Fable 5.2、在 Claude Code 中则相反；研究未测原生 harness，结果未必代表消费者体验。

编辑解读

ShellBench 把日常个人任务和多 harness 变量引入 Agent 评测，补充了此前偏重编码或专业任务的视角；但研究未测原生 harness，消费级产品体验仍需复测。

OpenAI Agent/开发者基础设施 Agent 技术 补录 · 2026-11-24 发布 simonwillison.net

历史学者案例记录：GPT-6.2 Astra 用 22 分钟自主锁定 1808 年匿名素描本作者。

事实摘要

Link Blog 上的一篇博文转述历史学教授 Mark Humphries 的案例：据其描述，GPT-6.2 Astra 仅用极少提示，自主辨认出耶鲁 Beinecke 图书馆所藏 1808 年匿名素描本的作者。

该案例记录称，它用时 22 分钟，使用公开的一手与二手资料，并在过程中发现纸质档案中的一份冷门文献，预判该文献经查阅可验证其假设，结果确实得到印证。

具体线索是：它发现一条日记记录提到 vicomte de Chabot 在素描本所记日期前五天到访附近河流，并建议查阅其旅行日志（需向克利夫兰州立大学订购），称这或许能确认素描本出自他之手。

Mark Humphries 认为，历史学界受到的冲击几乎肯定会比数学界温和，因为历史研究不断重释过去、不追求单一普适真相，且历史写作仍在一定程度上需要人的参与。

编辑解读

这条案例的可借鉴点在于 agent 把读线索、提假设、找冷门档案、建议订购原始文献串成闭环；但它只是单一案例的当事人转述，尚不足以证明历史研究被普遍自动化。

Simon Willison 行业动态 行业观点 补录 · 2026-11-24 发布 Simon Willison

Simon Willison 撰文称LLM过去12个月出现编码Agent、Fable级模型与3D建模三次能力拐点。

事实摘要

Simon Willison 在博客中称，过去12个月LLM与编码Agent的能力出现三次重要拐点。 他回顾2025年11月的编码Agent进展时称，Claude Opus 4.5是他首个在Claude Code里默认结果基本正确的模型；

同期GPT-5.1系列也让Codex对其许多编码任务可靠有用。 他称6月发布的Claude Fable 5是削弱版Mythos，上线三天后因美国出口管制被下架，直到7月1日才恢复；

他并把Fable 5、5.1、5.2、Opus 5.5、GPT-6 Astra归为Fable class。

他还把3D建模与游戏开发列为一次变化：2026年9月22日发布的Opus 5.5据其自述花12小时试玩新功能并重平衡数值，把一款命令与征服式RTS从无聊改到有趣。

编辑解读

文中“Fable class”不是厂商官方分类，而是作者按任务表现划出的非正式标签，清单含Claude Fable 5系列、Opus 5.5、GPT-6 Astra与可能算入的Gemini 4 Neon。

作者用五个WebAudio麦克风把房间里的神秘蜂鸣定位到约40cm范围内，这类具体案例可作为观察Agent调用工具解决实际问题的样本。

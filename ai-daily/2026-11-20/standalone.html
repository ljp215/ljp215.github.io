谷歌 模型/产品发布 基础模型与技术 补录 · 2026-11-18 发布 Google

谷歌发布 Gemini 4 Neon，面向复杂软件工程、知识工作与科学工作流，并同步开放 API、企业版与订阅用户入口。

事实摘要

谷歌于2026年11月18日发布 Gemini 4 Neon，面向复杂软件工程、知识工作与科学工作流提供端到端任务能力。 官方报价为输入 token 每百万 3美元、缓存输入每百万 0.15美元、输出每百万 15美元。

官方称其在 Artificial Analysis Intelligence Index xhigh 档获61分，并以70.9%位列 Vals Index 第二。

该模型将向 Google AI Studio/Gemini API、Gemini for business、Google Antigravity 和 Gemini app 的 Pro/Ultra 订阅用户提供，网络安全专家将在未来几天通过 Fairwind Program 获得访问权限。

编辑解读

Gemini 4 Neon 被官方定位为在推理深度和效率之间取得平衡的模型，与 Carbon 的长期项目、Hydrogen 的日常快速执行形成产品分层。

文中的性能排名、成本下降比例和安全基准均为谷歌官方或榜单口径，需等待第三方独立复现后才能作为采购依据。

Microsoft 模型/产品发布 AI 产品与工具 补录 · 2026-11-17 发布 Windows Blog

微软在 Ignite 2026 将 Edge for Business 的 Copilot Cowork 代理式浏览推向正式可用，可跨网站执行多步骤任务。

事实摘要

微软在 Ignite 2026 宣布升级 Edge for Business，并称其为全球使用率最高的企业浏览器；

Copilot Cowork 的代理式浏览已正式可用，可在侧边栏、新标签页和网页中跨网站完成多步骤任务，需启用按用量计费的 Microsoft 365 Copilot 许可。

Skills Recorder 可把一次完整流程录制为可复用、可分享的 Cowork 技能，计划年底前预览；微软称针对常见网页操作的早期内部测试平均减少 30% token 使用量。

托管代理浏览进入预览，微软及其他提供商的代理在独立窗口、以各自 Entra agent 身份、按用户权限和组织策略运行，需 Microsoft 365 E5 许可；Remix 已正式可用，Interactive Brief 计划年底前预览。

编辑解读

这次更新的关键不是再添一个 Copilot 按钮，而是把浏览器做成可承载受管代理的运行时：代理有独立 Entra 身份、继承用户权限，并在 IT 可见的独立窗口中运行。

Agent 365 与 Entra 日志的整合仍被描述为后续愿景，不能把“可治理”理解为已完全交付。

巴尔的摩县四名高中生起诉学校与警方：诉讼称Doritos零食袋触发AI枪支警报后，警方持枪到场并给学生戴上手铐。

事实摘要

2025年10月，四名黑人高中生在足球训练后分享Cool Ranch Doritos时，学校的AI枪支检测系统将其中一人手持零食袋标记为疑似枪手。 校方两分钟内查看监控、确认无威胁并取消警报，还通知巴尔的摩县警方无需响应。

诉讼称，因技术和人为错误，校方仍叫来警察；至少六辆警车到场，有警察持枪下车，学生被令跪下、戴手铐并遭搜查。 诉讼还称，直到未找到枪支，学生才知道触发响应的是学校使用的Omnilert AI系统；原告包括在校生和往届生。

编辑解读

这条诉讼把AI误报、人工复核与警方响应串成一条责任链，后续值得关注校方、警方与Omnilert的处置和披露。

vLLM 博客介绍将 AMD FlyDSL 编写的 MonoKernels 用于 vLLM，在 AMD Instinct GPU 上降低交互式 LLM 的小批量解码延迟。

MonoKernel 把多个依赖算子阶段合并进单次 GPU kernel launch，以 persistent launch、权重预取和按数据就绪的 mailbox handoff 缩短等待，并按模型定制边界；

该路径默认关闭，需 --monokernel 开启。

六个已合并 PR 在并发 1 对同节点 stock baseline 的 mono decode 加速为 1.20× 到 2.26×，由 PR 作者在 MI355X 或 MI325X 测得，并发升高后部分模型加速收窄。

编辑解读

这项优化的收益集中在低并发、单用户响应优先的 Agent/交互式场景；模型专属 kernel 边界和默认关闭策略说明它更像可按模型启用的专用加速路径，而非通用吞吐优化。

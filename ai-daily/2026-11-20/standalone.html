Google 模型/产品发布 基础模型与技术 补录 · 2026-11-18 发布 The Decoder

谷歌发布 Gemini 4 Neon，支持约100万 token 上下文，API 定价为每百万输入 token 3 美元、每百万输出 token 15 美元。

事实摘要

谷歌发布 Gemini 4 Neon，并已通过 API 提供调用。

其定价为每百万输入 token 3 美元、每百万输出 token 15 美元，高于 Carbon/Argon 的每百万输入 2 美元、输出 10 美元引入价，也高于 Hydrogen 的每百万输入 1.5 美元、输出 7.5 美元。

Neon 支持约100万 token 上下文和最多100万 token 输出，处理文本、图像、视频、音频与 PDF，并支持 Computer Use、代码执行、文件搜索及 Google 搜索和 Maps 接地。

它不支持图像和音频生成，基准测试在文章发布后数小时才公布；这也是谷歌四周内发布的第四款 Gemini 4 模型。

编辑解读

Gemini 4 Neon 的 API 价格为每百万输入 3 美元、输出 15 美元；同期 Carbon 和 Argon 的引入价为 2/10 美元，并将在 12 月 1 日翻倍至 4/20 美元。

LangChain Agent/开发者基础设施 Agent 技术 langchain

LangSmith Tool Gateway 进入公测，以单一 kit URL 统一 Agent 的 MCP 工具接入、身份与调用追踪。

事实摘要

LangSmith Agent Platform 上线 Tool Gateway 公测，后者作为托管工具层统一处理 Agent 每次工具调用的凭证、身份和访问。

团队可按 URL 注册 MCP 服务器或启用 Google、Microsoft、Salesforce、GitHub、Linear 等内置服务器，并用 kit 只向特定 Agent 暴露所需工具；

工具达数百到数千个时，search mode 可按任务加载相关工具以应对全量加载的延迟和选择困难。

每次调用可映射为“代表用户”或“代表 Agent”两种身份，管理员可配置拒绝策略与敏感操作人工审批，调用记录包含工具、服务器、用户、结果和耗时，企业版审计日志可跨组织追踪。

编辑解读

LangSmith 的 LLM Gateway 已负责模型调用的支出限制、回退、限流与敏感数据脱敏，Tool Gateway 与它并列，把可见性和治理扩展到 Agent 的工具调用。

KPMG 公司/行业动态 AI + 行业赋能 补录 · 2026-11-18 发布 The Decoder

KPMG 在一家 FTSE 250 公司完整年审中并行部署超 100 个 AI Agent，正式审计意见仍基于常规审计。

事实摘要

KPMG 内部代号“Project Exponential”的实验在一家 FTSE 250 公司的年度审计中并行部署超过 100 个 AI Agent，覆盖审计各阶段；据 The Decoder 援引《金融时报》报道，正式审计意见仍基于常规审计。

KPMG 英国审计主管 Cath Burnet 称，Agent 在若干问题上比常规团队挖得更深、提问更好，能独立收集、分析并记录数据、起草审计结论，但有一处 Agent 无法正确匹配法规与公司文件，需要人工介入。

实验中由两名合伙人、一名董事与高级经理及初级员工共同设定目标、提供上下文、定期复核并质疑结论；KPMG 计划扩展到最多 20 个更大审计项目，但表示尚不具备支撑数千次审计的规模，能可靠使用的客户数据仍然很少。

英国会计监管机构 FRC 近日发布指引，将现有独立性规则适用于 AI 使用，并指出 AI 深入分析数据后产生的额外发现，在某些情况下可能对审计独立性构成“明显威胁”。

编辑解读

这次实验可复用的形态是并行审计加人工设定目标、复核结论、逐字符与时戳可追溯的交互记录，而不是“Agent 替代审计师”；被点名的主要瓶颈是客户数据洁净度，而不是模型能力。

背景上，KPMG 曾因 Carillion 审计中长达 19 年未质疑管理层数据，两家实体合计被罚 2100 万英镑，审计独立性在英国属高度敏感议题。

Amazon Web Services (AWS) 模型/产品发布 Agent 技术 aws

AWS 为 AgentCore payments 增加 AWS Billing 结算，Agent 可用美元在 AWS Marketplace 购买 x402 服务

事实摘要

AWS 宣布，Amazon Bedrock AgentCore payments 新增 AWS Billing 支付选项，使 Agent 能发现并购买 AWS Marketplace 上支持 x402 的软件、API、数据和内容，按次以美元结算并计入开发者的 AWS 账单，无需稳定币钱包或 API 密钥。

AWS 还推出 AgentCore Gateway 的可选 AWS Marketplace 连接器，帮助 Agent 查找商品及其端点；

开发者可用 AgentCore policy 设定支出上限与允许的卖家，会话预算上限由 AgentCore payments 强制执行，交易可在 AWS CloudTrail 与 AWS Cost Explorer 中审计。

流程上，Agent 先发现商品，从卖家端点取得带签名的 HTTP 402 报价，由 AWS Marketplace 对照卖家注册密钥校验，再调用 ProcessPayment（AWS_BILLING_X402）取得支付 token 完成请求；

支付 token 约 5 分钟有效，结算异步进行并按月显示在 AWS 账单。 上线时，AWS Billing 支持 x402 的 exact 固定单价方案；

示例中默认会话预算为 0.05 美元、单请求上限为 0.02 美元，对 0.01 美元的卖家在比对两条商品后支付 1 次、合计 0.01 美元。

编辑解读

AgentCore payments 在 2026 年 8 月已正式可用，允许 Agent 通过 x402、MPP 等开放协议自主支付付费 API、MCP server 和网页内容；

本次是在此基础上增加 AWS Marketplace 采购与 AWS Billing 结算通道。

Google 模型/产品发布 Agent 技术 TechCrunch

Google 为 macOS 版 Gemini 加入 computer use，可代用户操作本地应用与网页。

事实摘要

Google 于周四宣布，在 macOS 版 Gemini 桌面应用中引入 computer use，让 AI 在后台导航原生 Mac 应用并浏览网站，代用户完成任务。

该功能首批仅在美国以英语提供，需要 macOS 版 Gemini 应用以及 Google AI Plus、Pro 或 Ultra 订阅，Google 未说明何时扩展到其他市场和平台。

Google 本周才宣布扩大 Gemini“Tasks”功能，并近期开始放行早期测试者试用 9 月发布的“CC”Agent。

编辑解读

把第三国云算力纳入许可，叠加封测与处理器出货收紧，中国大模型团队的海外训练通道和芯片采购同时受限；短期更值得观察集群交付、许可获批节奏与训练成本。

事实摘要

DeepSeek-V4.1-Flash TP2 从 1.35× 收窄到并发 8 时的 1.14×，MiniMax-M3 TP4 从 1.20× 到并发 16 时持平。 该路径默认关闭，按模型、TP 规模与 step width 专门编译；

预填充、混合批次或过宽 step 仍走 stock 层，也不保证覆盖任意模型或 batch size。

编辑解读

从作者报告看，这套方案把优化粒度从算子级推进到模型专用调度：低并发交互式解码有明确提速，但代价是模型、TP 规模和 step width 的定制维护，且并发升高后收益收窄，更适合定向部署而非通用加速。

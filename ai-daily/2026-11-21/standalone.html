这次定价为包括OpenAI在内的私人AI公司提供了新的估值参照；同时，约1.5万亿美元估值意味着公开市场会更直接审视其后续业绩。

Google DeepMind 模型/产品发布 基础模型与技术 补录 · 2026-11-19 发布 The Decoder

Google DeepMind 发布七周内第四款模型 Gemini 4 Neon，速度接近 Gemini 4 Carbon 的两倍、列表价低 25%。

事实摘要

据 The Decoder 报道，Google DeepMind 发布七周内第四款模型 Gemini 4 Neon，提供覆盖文本、图像、音频和视频的百万 token 上下文，Google 将其定位在 Gemini 4 Carbon 与 Hydrogen 之间。

该模型速度约 110 token/秒，接近 Carbon 的 57 token/秒两倍；

定价为每百万输入 token 3 美元、每百万输出 token 15 美元，比 Carbon 常规价 4 美元和 20 美元低 25%，但比 Carbon 仍在执行的促销价高 50%。

Artificial Analysis 测得 Neon 在最高推理档 xhigh 的智能指数为 61 分，Carbon 为 60 分，排在 GPT-6.2 Astra 与 Claude Fable 5.2 之后，而 Google 自己的对比表只列了 Claude Opus 5.5 与 GPT-6.2 Sol；

该机构测算 Neon 单任务成本 6.44 美元，低于 Carbon 未打折的 7.76 美元，但 Neon 每任务输出 token 比 Carbon 多约 15%，节省全部来自更低的每 token 挂牌价。

在 Google Antigravity 内的编码任务中，Neon 在 xhigh 档得 59 分，Carbon 为 55 分，Claude Fable 5.2 与 Opus 5.5 各 58 分，平均一次编码任务成本为 6.86 美元，对 12.61 美元和 15.47 美元；

Google 称在 SWE-sweep 测试中 Antigravity 环境将其命中率提高到 39.0%。

编辑解读

Google 在七周内连发四款 Gemini 4 系列模型，Neon 以更低单价和更高吞吐补位 Carbon 与 Hydrogen 之间，价格与速度成为这一轮 Gemini 4 序列的主要竞争维度。

LangSmith 推出编码 Agent ROI 报表，公开测试版可将花费归因到 GitHub PR 与 GitLab MR。

Google 模型/产品发布 Agent 技术 The Decoder

Google 为 Gemini Mac 应用推出 Computer Use，可在隔离后台窗口跨本地文件、桌面应用和网站执行多步骤任务。

事实摘要

Google 在 Gemini Mac 应用中推出“Computer Use”，让 Gemini 可跨本地文件、桌面应用和网站完成多步骤任务。 用户描述目标后，Gemini 会点击、输入并操作菜单和表单；

任务在带实时预览的隔离后台窗口运行，用户可选择可访问应用、观看每一步、随时暂停并预先批准关键操作。 Google 举例包括批量编辑照片和 3D 场景、用本地 PDF 填写发货表单和制作演示文稿；

文章称该功能在美国以英语推出，Gemini Mac 应用可供下载。

编辑解读

这次更新将 Gemini 的执行范围从对话扩展到本地文件、桌面应用和网站，并以隔离窗口、实时预览和关键操作预批准作为风险控制。

Hugging Face Agent/开发者基础设施 工程实践 补录 · 2026-11-18 发布 The Decoder

Hugging Face 将语言模型推理请求改由 OpenRouter 按价格、速度与可靠性路由。

事实摘要

Hugging Face 的 Inference Providers 现将语言模型请求交由 OpenRouter 路由，由后者按价格、速度和可靠性为每次调用选择供应商，并在故障时自动回退。

现有代码无需改动，开发者可用 :fastest、:cheapest 或直接指定供应商来控制路由；语言模型的 BYO API key 不再可用，图像和视频仍保留该方式。 Hugging Face 直接按供应商价格计费且不加价；

OpenRouter 自称新路由使容量错误下降 46%、首 token 时间改善 16.9%、吞吐提升 16.3%。

编辑解读

这次调整把供应商选择和故障回退交给 OpenRouter，开发者少管 API key，但计费与可用性更依赖单一中间层；自报的性能改善仍需独立复现。

Databricks 模型/产品发布 Agent 技术 补录 · 2026-11-19 发布 Databricks

Databricks Genie ZeroOps 进入公测：自动排查数据管道故障并生成修复 PR，私测累计 8 万多客户问题

事实摘要

Databricks 宣布 Genie ZeroOps 进入公测，工作区管理员可在 Previews 页面开启。

该 Agent 按检测、调查、验证、通知、修复五步自动处理管道问题：既监控作业失败，也通过数据质量监控发现表更新延迟、行数不足等静默异常。

调查时跨日志、源码、表元数据与血缘运行 SQL 定位根因，验证在沙箱用单元测试和 dry run 校验，修复阶段为 Git 作业生成预填信息的 PR。

Databricks 称有限私测期间在数百家公司观察到 8 万多个真实问题，其中过半需要组织特有知识才能排查和排序，因此新增共享收件箱、带摘要通知、自定义指令与一键 PR；

它沿用 Unity Catalog 权限，通知离开 Databricks 前对 PII 脱敏，且未经人工审核不会改动生产代码或数据。

编辑解读

关键不在自动化程度，而在边界：它由事件触发、无需提示词，但只做到沙箱验证与提 PR，生产代码和数据仍要人审；真正的门槛是自定义指令能否承载各团队的私有知识。

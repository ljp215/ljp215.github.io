01
Perplexity 模型/产品发布 Agent 技术 The Decoder

Perplexity 发布 Monitor API，可按计划监控网页并通过 webhook 把过滤后的变化推送给 AI Agent，网页监控定价为每 1000 次成功运行 1 美元。

事实摘要

Perplexity 推出 Monitor API，可按计划执行网络搜索或跟踪固定网页，并通过 webhook 把过滤后的变化推送给应用与 Agent，一次 API 请求即可设定查询、目标、计划和回调地址。

该 API 分网页监控和页面监控两种模式，页面监控最多跟踪 10 个页面，首次运行保存基线版本、之后返回文本 diff，调度间隔可从每 15 分钟到每周或自定义 cron。

结果由 Perplexity 自有的决策模型按开发者用自然语言设定的目标，从相关性、来源可信度、新颖性和时效性等维度过滤，全部阈值达标才带置信度推送。 定价为网页监控每 1000 次成功运行 1 美元、页面监控每 1000 个抓取 URL 1 美元；

Perplexity 称内部早期测试在 60 个主题的前 8 小时返回 63 条新鲜相关页面，Firecrawl 为 20、Exa 为 15、Parallel Core 与 Lite 各 10，并说明这是内部早期结果。

编辑解读

文章提到 Perplexity 正押注 Computer、常驻 Teammates 以及 Search as Code 等 Agent 与开发者工具，Monitor API 延续的是这条产品化路线，而不是新的模型能力。

该对比测试由 Perplexity 自行组织，各提供商使用各自的调度与设置，并由单独模型打分，因此只能视为厂商自述的早期数据。

Anthropic 融资/收购/估值 行业 / 商业动态 补录 · 2026-11-20 发布 CNBC

Anthropic上市首日募资813亿美元，CNBC称约9000亿美元算力承诺的按期交付仍是一项主要不确定性。

事实摘要

据CNBC报道，Anthropic在11月19日IPO首日获投资者溢价认购，在上市中募资813亿美元。 公司披露已签订约9000亿美元的算力与基础设施采购承诺和租赁协议，其中约一半预计2030年前支出，其余在2031至2045年之间。

这些支出中约1860亿美元可终止或受融资、设施和监管审批等条件约束；Lambda未按期取得一项349亿美元协议的设施租约，Nscale也称其与Anthropic价值最高约440亿美元的合同尚未获得有约束力融资承诺。

Futurum Group的Nick Patience表示需求超过供给、缺失容量会很快变成收入损失，Morningstar的Malik Ahmed Khan预计Anthropic在2027至2028年仍受算力约束。

编辑解读

后续应跟踪约9000亿美元算力承诺中有多少转为有约束力合同并按期上线，而不是只看IPO募资额。

Thinking Machines 模型/产品发布 基础模型与技术 补录 · 2026-11-21 发布 The Decoder

Thinking Machines 发布开源模型 Inkling 2 Mini：24 层中 12 层循环三次，权重可在 32GB Mac 本地运行。

事实摘要

Thinking Machines 发布了开源模型 Inkling 2 Mini，其采用环路 Transformer 结构，每个 token 会连续重复执行 24 层中的 12 层三次。

据 Thinking Machines 称，Inkling 2 Mini 是 MoE 模型，总参数 26.4B、每 token 激活 5.4B，支持文本与图像、1M token 上下文，并采用 Apache 2.0 许可。

据 The Decoder 报道，Inkling 2 Mini 在 100B 参数以下开源模型的 agentic coding 测试中取得 48.2% 的 DeepSWE v1.1 得分与 46.5% 的 Vals Index v2.2 得分；

Artificial Analysis 智能指数为 20 分，与 Qwen3.8 27B 持平。

原文称，权重及可变环路研究版可从 Hugging Face 下载，模型可在内存至少 32GB 的 Mac 和 Nvidia DGX Spark 上本地运行。

编辑解读

环路设计把重复计算放在层内而非生成更多 token，Thinking Machines 称这样可延长内部推理并以更少 token 得到答案；该效果属于厂商自报，原文未给出独立复现。

据 The Decoder 报道，Inkling 2 Mini 在 100B 参数以下开源模型的 agentic coding 测试中报告了 DeepSWE v1.1 48.2% 与 Vals Index v2.2 46.5% 的得分；

报道未说明独立测试方，这些分数不宜直接视为全面优于所有竞品。

这更像是AI Agent的责任边界被合同化：银行用条款和凭证限制第三方代理，平台则直接阻止代理下单，同时继续自建第一方工具。对开发者而言，跨应用代操作若绕不开用户凭证或平台授权，金融、零售和航旅会先变成高摩擦场景。

Signal 监管/安全/隐私 政策、安全与社会影响 补录 · 2026-11-21 发布 TechCrunch

Signal 在 Android 与 iOS 默认限制截图，称操作系统级 AI Agent 读取屏幕削弱其独立保证隐私的能力。

事实摘要

据 TechCrunch 报道，Signal 宣布在 Android 和 iOS 应用中限制用户截图，此前其 Windows 应用已默认阻止截图。

Signal 总裁 Meredith Whittaker 称，操作系统为服务 AI Agent 能力而捕获、存储屏幕上的敏感数据，并将其提供给本地数据库或远程服务器，这些数据一旦被捕获就超出 Signal 的控制范围。

Whittaker 表示用户可自行关闭该设置，但那会“破坏我们的隐私保证”，她也承认这是不完整的方案，未覆盖 AI Agent 访问应用数据的其他更隐蔽方式。

编辑解读

端侧 AI Agent 的屏幕读取能力正把隐私边界从应用层挤向操作系统层，端到端加密应用能做的只剩默认关闭截图，而用户可自行解除，实际约束力有限。

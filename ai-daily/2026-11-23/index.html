Perplexity Agent/开发者基础设施 Agent 技术 The Decoder

Perplexity 发布 Monitor API：按计划监测网页，筛选后仅通过 Webhook 推送相关变化。

事实摘要

Perplexity 推出可用的 Monitor API，开发者用一次请求设定查询、目标、调度与 Webhook URL，让 Agent 仅在监测到相关变化时收到更新。

该 API 有 Web 与页面两种监测模式，页面模式最多跟踪 10 个页面，首轮存基线并返回文本差异；结果经相关性、来源可信度、新颖性和时效性过滤，全部达标才推送带置信分数的更新。

定价为 Web 监测每 1,000 次成功运行 1 美元、页面监测每 1,000 个抓取 URL 1 美元；

Perplexity 称早期内部测试在 60 个主题的首 8 小时交付 63 个新鲜相关页面，Firecrawl 为 20、Exa 为 15、Parallel Core 和 Lite 各 10，但强调这是早期内部结果。

Wells Fargo 公司/行业动态 Agent 技术 WIRED

Wells Fargo 更新客户协议称第三方 AI Agent 风险自负，多家美国银行与 Amazon、United 同步收紧 Agent 权限。

事实摘要

据 Wired 报道，Wells Fargo 将向数百万客户启用更新后的协议，明确“使用任何 AI Agent 风险自负”，把第三方 Agent 操作的后果归于用户。

此前 JPMorgan Chase 在 10 月底修改条款，禁止使用用户凭据登录的第三方 Agent，Bank of America 同日警告客户不要向 Agent 共享登录信息，Citibank 和 PNC 也加入了 Agent 相关警告条款。

收紧不止于银行：Amazon 阻止 Meta 的 Muse 在其平台下单，United 宣布禁止个人 bot 代购机票，American Express 则表示未来部分 Agent 误操作可能获得赔付。

与此同时银行在推自有工具，Wells Fargo 的生成式 AI 问答工具交互已超过十亿次，Citigroup 上线了以 Agent 为核心的内部开发平台。

编辑解读

银行把责任边界写进条款，是在第三方 Agent 可靠性尚未被证明前先划清赔付责任；同时它们又在自建 Agent 工具，态度是渠道控制而非全面排斥。

Thinking Machines 模型/产品发布 基础模型与技术 补录 · 2026-11-21 发布 The Decoder

Thinking Machines发布开源循环Transformer Inkling 2 Mini，可在至少32GB内存Mac本地运行。

事实摘要

Thinking Machines发布开源循环Transformer模型Inkling 2 Mini，每个token将24层中的12层连续运行三次，公司称这让模型在内部推理更久而不必生成更多文本。

该MoE模型总参数26.4B、每token激活5.4B，支持文本与图像、100万token上下文和Apache 2.0许可，可在至少32GB内存Mac或Nvidia DGX Spark本地运行。

据文章，在100B参数以下开源模型的Agent编程测试中，Inkling 2 Mini的DeepSWE v1.1得分为48.2%、Vals Index v2.2为46.5%，Artificial Analysis Intelligence Index为20分，与Qwen3.8 27B（xhigh）和Nanbeige4.3-33B持平，报道称其成本约低六倍、速度约为四倍。

权重和研究版（可变循环）已在Hugging Face提供下载，也可在Tinker Playground试用。

编辑解读

据Thinking Machines称，Inkling 2 Mini的循环层让模型在不生成更多文本的情况下进行更长时间内部推理，从而以更少token找到答案；

Artificial Analysis给出的AI指数20分显示其与Qwen3.8 27B、Nanbeige4.3-33B同分，实际收益还需结合速度、本地运行内存与Agent任务表现考察。

文末相关报道列出2026年11月6日的Inkling 2 Small和2026年7月31日的Inkling Small，后者被描述为Thinking Machines在规模与效率之间选择效率的第二款模型。

02
METR 研究/Benchmark 政策、安全与社会影响 The Decoder

METR 警告 AI 研究能力提升快于专家可靠测试系统安全的能力，模型可处理任务长度每 3.6 个月翻倍。

事实摘要

METR 警告，AI 模型在 AI 研究任务上快速进步且越来越难测量，现有公开数据不足以排除未来几年 AI 研究出现急剧加速，这可能削弱人类理解、评估并应对灾难性风险的能力。

其分析覆盖 Opus 5.5、GPT-6 Astra 等领先模型：在有明确反馈的编程和计算任务上，模型多数时候已胜过有经验的人类专业人士，但尚未超过顶尖专家的大群体；

对人类耗时更长的任务，模型可处理的任务长度每 3.6 个月翻倍，朴素外推显示到 2027 年 7 月，最长 200 小时任务的成功率可达 50%。

METR 同时指出，模型在缺乏即时反馈、需要真实判断的开放式问题上仍吃力，常见且易运行的测试可能因训练环境相似而高估模型真实表现。

编辑解读

对开发与部署团队而言，长任务能力持续翻倍时，单靠公开基准和易运行测试难以支撑安全判断，需补上更贴近真实工作流、可复现的私有评测。

Kimi Code CLI（Moonshot AI） Agent/开发者基础设施 工程实践 补录 · 2026-11-20 发布 aws

Kimi Code CLI v2.7.0 新增原生 Amazon Bedrock provider，可用 AWS 凭证链替代单独 API 密钥。

事实摘要

AWS 机器学习博客发文介绍，Moonshot AI 的 Kimi Code CLI 在 v2.7.0 中加入原生 bedrock provider，可直接使用 AWS 标准凭证链（含 named profile 与 SSO），不必再单独申请和保管 Amazon Bedrock API key。

该 provider 通过 @aws/bedrock-token-generator 生成短期 Bedrock API key，有效期最长 12 小时或为 AWS 会话时长，以两者中较短者为准，因此无需把 AWS access key 或手工生成的 Bedrock key 写入 Kimi Code 的 config.toml。

教程以 Kimi K3.1 Pro Highspeed 为例，示例配置声明 100 万 token 上下文窗口，以及 always_thinking、thinking、image_in、tool_use 四项能力，模型通过 global.moonshotai.kimi-k3.1 全局推理配置调用。

文中同时说明，目前 Kimi Code 的桌面端和网页端创建 provider 界面未暴露该凭证链方案所需的全部环境字段，需直接编辑 config.toml；Kimi Code 也不会自动探测 Bedrock 上多数模型的能力，须按各模型卡手动声明。

编辑解读

旧版做法是在配置里写 type="openai" 或 "openai_responses"、填区域 base_url 并提供 Bedrock API key，本次改动正是把这套独立凭证换成环境凭证链。

新路径减少了手工管理 API key 的依赖，但 AWS 明确表示凭证保护与权限最小化仍由使用者负责，生产环境应单独设 IAM 角色。

LangChain Agent/开发者基础设施 Agent 技术 补录 · 2026-11-21 发布 langchain

LangChain 提出“知识工厂”方案：让 Agent 标记知识缺口、由后台 curator agent 定期维护技能与领域知识。

事实摘要

LangChain 在官方博客中提出“知识工厂”概念，认为企业落地 AI 的缺口不在更强模型或更多上下文，而在如何收集、整理并持续维护公司内部的隐性知识。

该方案把知识分为技能、领域知识和数据访问指引三类，由 Agent 在工作中标记缺失或错误信息，再由后台 curator agent 按节奏读取 Notion、Slack 等原始数据源和 Agent trace 进行更新。

LangChain 称其内部 GTM 与内容工作室 Agent 已由知识工厂驱动，LangSmith Engine 也为每个 Agent 维护一套知识工厂，并称正与少数客户合作将方案接入其内外部 Agent。

文章也承认知识存储格式尚无行业标准，语义记忆的表示方式仍待探索，建议不要过早规定格式。

编辑解读

这是 LangChain 基于自身实践的方法论分享，而非新模型或新产品发布；其效果目前只有厂商自述，缺少第三方复现。

《卫报》分析CoreWeave负债470亿美元，GPU抵押债务凸显AI数据中心融资风险。

事实摘要

《卫报》刊文分析CoreWeave的债务驱动扩张，称其通过借款建设AI数据中心，目前负债470亿美元，其中超过100亿美元明年到期。 文章称CoreWeave上季度营收36亿美元、亏损7.09亿美元，债权人一度把其未来五年违约概率估到60%以上。

英伟达持有其约11%股份，并有63亿美元采购承诺为其算力兜底；CoreWeave还以GPU和客户合同作抵押借款近250亿美元。 Forrester分析师则指出，其“产生”的现金约三分之二来自客户预付款，而非已交付服务的利润，收入质量仍需观察。

编辑解读

CoreWeave把GPU和长期客户合同打包成抵押品，使算力基建的债务风险与前沿AI公司的偿付能力绑定在一起。

TechCrunch 访谈中，Paris Marx 称数据中心扩张不可持续，社区反弹已跨党派。

事实摘要

TechCrunch 刊出对记者 Paris Marx 的访谈，围绕其新书《Hyperscale》讨论数据中心与生成式 AI 的物理影响。

Paris Marx 称数据中心建设“根本不可持续”，并引用爱尔兰数据中心用电占全国逾20%、谷歌在 The Dalles 使用该市29%水量等案例说明社区压力。

他还称，微软、亚马逊和 OpenAI 已表示将不再在与地方政府的谈判中使用保密协议，但认为这类回应作用有限。

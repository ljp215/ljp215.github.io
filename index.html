NVIDIA 公司/行业动态 人才与组织 补录 · 2026-11-23 发布 CNBC

英伟达董事会恢复黄仁勋 CEO、总裁及董事职务，代管 11 天的克雷斯继续担任 CFO。

事实摘要

CNBC 报道，英伟达董事会在黄仁勋因个人关系披露辞职后，恢复其 CEO、总裁及董事职务，代管公司 11 天的 CFO 科莱特·克雷斯继续担任 CFO。 公告发布后，英伟达股价上涨 31%，纳斯达克指数上涨逾 6%。

编辑解读

这次反转的核心是创始人风险与治理：黄仁勋回归迅速结束 11 天代管期，克雷斯留任 CFO 维持财务与融资管理连续性，但单日 31% 的股价反应也显示市场对创始人个人高度依赖。

美国AI芯片出口新许可覆盖新加坡等五国，彭博称与亚洲数据中心建设相关的融资被暂停数十亿美元。

事实摘要

据彭博报道，贷款机构暂停了与字节跳动、阿里巴巴和腾讯相关的数十亿美元融资，新限制可能拖慢亚洲数据中心建设。 美国政府宣布，新加坡、马来西亚、印尼、泰国和巴西的公司购买美国芯片需政府许可；已向中国公司出租算力的数据中心有90天申请单独许可。

巴克莱分析师称，这标志美国半导体管制从限制先进芯片实际流向，转向管制作算力的最终访问者，并波及亚洲经济体。

智谱 Z.ai 模型/产品发布 基础模型与技术 补录 · 2026-11-23 发布 The Decoder

智谱 Z.ai 发布 750B 旗舰模型 GLM-5.4，称其为自家首款循环 Transformer 大模型。

事实摘要

Z.ai（智谱）将旗舰模型迁移到循环架构，新旗舰 GLM-5.4 是公司首款基于循环 Transformer 的大模型，部分网络层在一次前向中会被执行两次。

该架构让一组共享层被重复运行，以上一轮的中间结果作为下一轮输入，从而在不增加参数的情况下加深网络。 据 Z.ai 自己的说法，这一 7500 亿参数模型的能力可对标 2 至 3 万亿参数级别的模型；

报道同时提到 OpenAI 自 GPT-6 Astra 起已采用类似架构。 Z.ai 把 GLM-5.4 定位为“Generalized Coding”的起点，即由代码进一步生成视频、游戏和 CAD 模型。

编辑解读

可获取的原文部分只披露架构机制与参数规模，未给出基准分数、开放权重或 API 范围与定价，其余内容位于付费墙之后。

若循环共享层块在真实负载下确实成立，其主要收益应体现在同等效果下的显存占用与单位算力成本，而“7500 亿对标 2–3 万亿”目前仅为公司自测口径，尚无第三方复现或测试条件披露。

Meta 模型/产品发布 Agent 技术 补录 · 2026-11-24 发布 Meta Newsroom · The Guardian

Meta 在英国上线个人 AI 智能体 Muse，由 Meta Superintelligence Labs 首个模型 Muse Spark 驱动。

事实摘要

Meta 于 2026 年 11 月 24 日发布公告，宣布个人 AI 智能体 Muse 在英国上线，面向 18 岁以上用户开放 iOS、Android、muse.ai 与 WhatsApp 入口，多数功能免费并提供订阅方案。

Meta 称该智能体由 Meta Superintelligence Labs 的首个模型 Muse Spark 驱动，可把用户请求转成计划、跨已连接的应用与网站执行任务，并在发送邮件、下单等重要动作前请求用户批准。

据《卫报》报道，Meta 已在英国与 14 家企业签约，包括 Marks & Spencer、Sainsbury's、easyJet 与 Trainline，让 Muse 更顺畅地浏览这些网站；

支付环节则接入 Stripe 的 Onelink 与 Shopify 的 Shop Pay。

按 Meta 说明，每个 Muse 在云端拥有独立虚拟电脑存放登录信息，对话与该虚拟电脑中的数据不进入 Meta 广告系统，用户可关闭用交互数据训练 AI 的选项。

编辑解读

地域扩张之外，更值得注意的是 Meta 首次用自己的 Muse Spark 驱动消费级 Agent，把网页操作、支付凭证与账号权限收进同一产品，这类权限聚合的可靠性与责任边界比功能清单更决定可用性。

Signal 监管/安全/隐私 政策、安全与社会影响 补录 · 2026-11-24 发布 CNBC

Signal 宣布在 iOS 屏蔽截图、Android 检测到 AI 助手读屏时启用屏幕保护，限制系统级 AI Agent 读取应用内容。

事实摘要

Signal 称 Google Gemini、Apple Siri 等具备屏幕感知能力的系统级 AI Agent 可以“扫描”用户屏幕，可能在其控制之外捕获并存储 Signal 数据；

为此 Signal 表示将在 iOS 端屏蔽截图，并在 Android 端检测到 AI 助手尝试读屏时启用屏幕安全。

Signal 基金会主席 Meredith Whittaker 在博客中称，应用开发者缺乏阻止 AI Agent 破坏应用级隐私的可靠工具，并呼吁 Apple、Google、Microsoft 提供简单技术工具和准确文档；

Signal 去年曾对 Windows 11 上的 Microsoft Recall 采取类似限制。

报道称 United Airlines、JPMorgan Chase、Charles Schwab、Morgan Stanley、OCBC 等也在限制或封堵第三方 AI Agent；

AvePoint 对 750 名全球 IT 负责人的调查称，88.4% 的受访组织过去一年至少经历过一次与 AI Agent 相关的安全事件。

Whittaker 也承认，新防护并未覆盖 Agent 获取数据的全部途径，包括读取用户设备上已存储的内容。

编辑解读

Agent 权限正从模型能力问题变成应用与操作系统的对抗：只要系统级读屏能力存在，单个应用的自保手段就只能是补丁式的，Signal 自己也承认应用层防护“总会有缺口”。

对要接入账户、支付和订票的企业来说，更现实的路径是按任务风险分层授权，而不是对第三方 Agent 一律放行或一律封堵。

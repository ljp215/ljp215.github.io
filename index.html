Salesforce 融资/收购/估值 行业 / 商业动态 Salesforce News

Salesforce签署最终协议收购Cresta，语音AI代理将整合进Service Cloud与Agentforce体系。

事实摘要

Salesforce于11月2日宣布已签署最终协议收购Cresta，后者定位为语音优先的客户体验操作系统，其语音代理可端到端解决复杂客户来电，并实时指导人工坐席、分析每次交互。

Cresta的语音代理已在Marriott、Comcast、Alaska Airlines等大型品牌规模化运行，交易预计在Salesforce 2028财年第一季度完成，仍需满足监管批准等惯常交割条件。

Salesforce计划将Cresta的实时对话智能与Agent能力嵌入其客户服务平台，交易完成后Cresta将继续支持现有客户使用的联络中心和电信平台。

编辑解读

这笔并购是Salesforce推进Agentforce与Service Cloud融合的重要一步，后续可观察Cresta语音代理能否在Salesforce渠道中扩大企业级采用。

Circle K Agent/开发者基础设施 AI + 行业赋能 aws

AWS 案例：Circle K 用 Amazon Bedrock 构建告警分类 Agent，平均耗时降至 15 分钟以内。

事实摘要

AWS 官方博客与 Circle K 工程师联合介绍，Circle K 将人工 45–60 分钟的告警排查流程，替换为基于 Amazon Bedrock 的自动化事件分类系统，能在告警触发后数分钟内把结构化结论发到 Slack。

系统先用 Amazon Bedrock Flows 并行运行 AWSResourceExplorerAgent（查 ECS、负载均衡、CloudWatch）和 OpenSearchExplorerAgent（查日志与调用链、独占知识库），再由 GitHubExplorerAgent 检索代码与近期提交，最后由单次模型调用生成根因、证据、负责人与修复建议。

上线后平均事件分类时间降至 15 分钟以内，按团队内部指标较人工流程缩短 67–75%，完整链路耗时 5–15 分钟；

该团队其后将架构迁移到 Amazon Bedrock AgentCore Runtime，把三个专用 Agent 合并为单 Agent，并支持最长 8 小时会话。

编辑解读

该案例的性能数字来自 Circle K 内部指标，发布方为 AWS，属于客户与云厂商联合撰写的方案说明，不等同于独立第三方基准。 值得后续观察的普遍问题是 Agent 结论的采纳率、人工复核成本，以及日志持续增长后长会话方案的稳定性。

预计阅读 2 分钟
02
Olam Labs（与 Y Combinator Labs 联合研究） 研究/Benchmark Agent 技术 The Decoder

Y Combinator Labs 与 Olam Labs 联合实验：50 个 GPT-6.1 Sol 智能体在 Minecraft 协作中陷入官僚僵局，竞技中却下载源码战胜 Claude

事实摘要

Olam Labs 与 Y Combinator Labs 的 Minecraft 'Civ50' 实验中，50 个 GPT-6.1 Sol 智能体首夜死亡 22 次、全程交换约 5,900 条消息，随后陷入极端官僚化：四名智能体为一块骨粉辩论 11 分钟 '肥料官' 人选，还制定了禁止投掷食物的交接协议。

竞技中同一模型表现迥异：Bed Wars 6-3、Mindustry 6-1 分别战胜 Claude Opus 5.5，GPT 还下载 Mindustry 公开源码调整战术，而 Claude 未搜索游戏代码。

研究者称，可复现游戏模拟可预警多智能体群体行为，并已开源 Mindustry 环境与 Multi-Agent Harbor 框架。

编辑解读

实验的可迁移价值在于把多智能体行为当作可测量的系统风险：协作场景中凸显极端风险规避与流程膨胀，竞争场景中又出现主动获取外部信息的自我扩展行为；研究团队明确把该结论映射到生产编码环境，部署 agent 群体的团队可据此设计可观测性和安全边界。

不过，这些结果来自研究团队的合作报告而非独立机构复现，且源码下载发生在允许访问公开游戏代码的沙箱中，不能据此断言 GPT 系整体强于 Claude 或存在越权行为。

LangChain 行业动态 工程实践 langchain

作者表示，这些问题在 LangChain 和业界都还没有解决方案，至少没有通用方案，这正是当前 Agent 工程最活跃的问题域。

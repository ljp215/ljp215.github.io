Deepgram 收购语音 AI 框架 Pipecat 开发商 Daily，并联合推出实时上下文标准

事实摘要

Deepgram 于 10 月 29 日宣布收购 Daily，后者是开源语音 AI 框架 Pipecat 的创建者和维护者。 交易金额未披露，双方表示 Pipecat 将继续保持开源。

Deepgram 同时推出了与 Pipecat 团队共同开发的实时上下文标准 (RCS)，这是一个为语音代理定义音频上下文、模型指令和响应风格的开放协议。

编辑解读

此次收购将 Deepgram 的语音模型能力与 Daily 的实时音视频基础设施经验结合，可能加速语音代理生态的标准化。

LangChain Agent/开发者基础设施 Agent 技术 补录 · 2026-10-28 发布 langchain

LangChain 以 OpenWiki 与确定性证据图构建 agent 记忆层：跨源问答准确率约为仅搜索的 5 倍，叠加证据图后再升 27%、每次正确回答成本降 58%。

事实摘要

LangChain 发布工程博客，介绍以开源 wiki 编译器 OpenWiki 为记忆层、再用轻量证据图把引用转为类型化边的 agent 持久记忆构建方案。

测试在自建的 111 份合成保险文档语料上进行，跨文档关联问答中 OpenWiki 记忆层使 agent 准确率约为仅搜索的 5 倍（0.10 对 0.52），简单查询场景下两者准确率接近、无记忆 agent 更快。

在 wiki 基础上加入证据图后，准确率再提升 27%、引用一致性翻倍、中位回答时间下降 40%、每次正确回答成本下降 58%，证据图构建无需额外模型调用。

OpenWiki 将 111 份文档编译为约原规模十分之一的 wiki 花费 4.15 美元，后续新增文档每份约 0.09 美元。

编辑解读

记忆层方案在需跨来源、重复推理的场景收益明显，简单查询场景不划算；证据图可从 wiki 现有引用确定性构建，无需额外模型调用，适合作为后续 agent 记忆工程的可复现参考基线。

预计阅读 2 分钟

Unsloth Agent/开发者基础设施 AI 产品与工具 补录 · 2026-10-28 发布 unsloth

Unsloth 发布万圣节主题更新：多 LoRA 微调任务可共享基座批量训练，启动与工具调用多项加速。

事实摘要

Unsloth 发布包含十一套主题界面的万圣节更新，并针对首次启动、工具调用和模型加载做了多项优化。 官方自测显示，首次启动约快 2 倍；Linux 下带 2GB 服务器进程时，工具调用延迟从 84-174ms 降至 1-2ms；

497 个缓存模型时，模型列表 CPU 时间降至约三分之一；1000 行数据集准备从 6.6s 降至 1.75s（Gemma 3 4B）。 新增多 LoRA 批处理：最多 4 个兼容的排队微调任务共享基座模型并行训练，各带独立适配器；

官方测试显示，4 个适配器时 4096x4096 层前向与反向比逐个运行快 1.52 倍（A100, bf16, rank16）。

推理侧，vLLM 与 SGLang 支持恢复被截断的回复和 JSON 输出，SGLang 可显示 Qwen3、DeepSeek R1 等思考模型的推理过程；桌面端新增浏览器控制开关。
